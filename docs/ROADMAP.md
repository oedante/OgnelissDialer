## Идеи на 1.3 — решать по отзывам

**Экран вызова**
- ✅ 1.5.1: живой фон по состоянию вызова — пятна цветов темы
  (`RELEASE_NOTES_1.5.1.md`, §5). Прежний замысел:
  спокойная анимация по состоянию вызова: мягкая пульсация вокруг
  портрета при входящем, «дыхание» при соединении. Только по состоянию,
  не по звуку: чтобы волны отвечали голосу, нужен доступ к микрофону
  или звуку разговора — у приложения его нет и не должно быть.
  С уважением к системной настройке «Убрать анимацию».

  как обычно.

**Данные**

  (без сети — только локальный файл).

**Доступность**

в интернет, но ждут, пока их попросят в отзывах:
