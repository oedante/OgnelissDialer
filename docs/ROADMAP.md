## Отложенное (накопилось за сентябрь)

- Проверка возможностей вызовов на живых звонках — план в
  `CALL_FEATURES.md` (второй входящий, конференция, удержание).
- Проверка миграции базы 5 → 6 на устройстве со старыми данными.
- Вычитка немецкого и французского носителем.
- `android.newDsl=false` — снять, когда выйдет плагин Baseline Profile,
  проверенный с AGP 9.
- Room: генерация кода на Kotlin вместо Java (`room.generateKotlin`).
- compileSdk 37 и новый Compose — отдельным выпуском с проверкой.
- Обложка карточки под строкой состояния — нужен пересмотр отступов
  корня приложения; сейчас сверху остаётся полоска фона.
- Сервер спама: юридическое заключение и решение по спутнику.

## Идеи на 1.3 — решать по отзывам

**Экран вызова**
- Спокойная анимация по состоянию вызова: мягкая пульсация вокруг
  портрета при входящем, «дыхание» при соединении. Только по состоянию,
  не по звуку: чтобы волны отвечали голосу, нужен доступ к микрофону
  или звуку разговора — у приложения его нет и не должно быть.
  С уважением к системной настройке «Убрать анимацию».

**Защита от спама**
- Расписание: неизвестные номера ночью — тихо или в блок, днём —
  как обычно.

**Быстрый доступ**
- Виджет на рабочий стол: закреплённые контакты и последние вызовы.

**Данные**
- Автоматическая резервная копия раз в неделю в выбранную папку
  (без сети — только локальный файл).

**Доступность**
- Проход с TalkBack по всем экранам: подписи, порядок фокуса.
