# План выпуска 1.4.0

Составлен 05.10.2026. **Поправка 05.10:** версии 1.3.x уже выходят
к пользователям (отзывы — с 1.3.4), поэтому 1.4.0 — не «первый выпуск
после внутренних тестов», а следующая крупная версия. Проверка
и поэтапная публикация из §3–§4 действуют для каждой 1.3.x.

```
versionName  1.4.0
versionCode  34
Публичная версия до неё: 1.3.1 (versionCode 29)
```

## 1. Что входит

Всё из 1.3.2–1.3.5 (подробно — `docs/RELEASE_NOTES_1.3.x.md`). Для людей:

- **новый вид:** иконки Material Symbols Rounded, экран вызова с фото
  контакта на весь экран, единая дизайн-система;
- **карточка контакта:** кнопки внизу, история по дням, удаление контакта,
  почта («Написать» / «Скопировать»), голосовая почта — переключатель;
- **свайпы:** новый API, меньше ложных срабатываний при прокрутке;
- **закрепление контакта целиком**, со звонками с любого его номера;
- **экстренные номера:** без лишних предупреждений; два часа после вызова
  экстренной службы фильтр пропускает все входящие;
- **быстрее:** тёплый запуск −9%, открытие карточки −12%,
  клавиатуры −11% (замеры 1.3.4).

Под капотом: AGP 9.4.1, compileSdk 37, Kotlin 2.4.20, Compose 1.12.1,
Lifecycle 2.10.0, Hilt 2.60.1.

## 3. Проверка перед отправкой — на подписанной release-сборке

**Обновление с данными, а не чистая установка (главное).** Поставить 1.3.1
из магазина, завести заметки, напоминания, чёрный и белый списки, метки,
закреплённые номера, быстрый набор, свои настройки; обновиться до 1.4.0
поверх. Всё на месте; закреплённые номера переведены на контакты.

**Экстренный вызов** (без набора: проверить ветку кода на тестовом номере
или на эмуляторе) — нет предупреждения о платном номере; после — входящие
два часа не фильтруются.

**Разрешения:** каждое обязательное — разрешено; запрещено впервые;
«больше не спрашивать»; отозвано в настройках при открытом приложении.
Везде — объяснение и путь в настройки, без падений.

**Жизненный цикл:**
1. Открыть → свернуть → вернуть → повернуть → убить процесс
   (`adb shell am kill com.ogneliss.dialer`) → открыть.
2. Открыть карточку → в фон → входящий → завершить → вернуться в карточку.
3. Начать поиск → сменить тему → повернуть → вернуться — запрос на месте.

**Сценарии пользователя:** позвонить → завершить → журнал → карточка →
перезвонить; пропущенный → уведомление → перезвонить; T9 → позвонить
с нужной SIM; входящий от незнакомого → отметить как спам.

**Каждая сборка:** входящий, исходящий, пропущенный; удержание и второй
вызов; громкая связь; карточка (номера, почта, «Написать»); свайпы; светлая,
тёмная, AMOLED; поворот; смена языка.

**Устройства:** nubia NX721J (Android 15) — основное; эмулятор Android 8.0
(minSdk 26); эмулятор Android 16; планшет или складной эмулятор.

## 4. Публикация

1. `versionCode 34`, `versionName "1.4.0"`; `RELEASE_NOTES_1.4.0.md` —
   сводка для людей из §1.
2. `generateBaselineProfile` → `bundleRelease` → загрузить AAB.
3. Внутренний тест — 1–2 дня на своём телефоне.
4. Рабочая версия — **поэтапно**: 10% → 2–3 дня → 50% → 2–3 дня → 100%.
   Между этапами — Play Console → Android Vitals: падения и ANR не выше,
   чем у 1.3.1.
5. Плохо — «Остановить выпуск» в консоли (у вставших на 1.4.0 останется;
   исправление — 1.4.1 с versionCode 35).
6. Тег в git: `git tag v1.4.0`.
