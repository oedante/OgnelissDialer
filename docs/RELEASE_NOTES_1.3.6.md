# Ogneliss Dialer 1.3.6 — к публикации

```
versionName  1.3.6
versionCode  34
Предыдущая версия: 1.3.5 (33) — собиралась 06.10.2026
```

Номер поднят для публикации (06.10.2026): сборка 1.3.5 с versionCode 33
уже собиралась, а после неё код менялся — повторно номер 33 Google Play
не примет.

## Что входит

Всё из 1.3.5 (`docs/RELEASE_NOTES_1.3.5.md`, разделы 1–18) вместе
с исправлениями 06.10.2026:

- буквы вместо значка у контактов без фото — и в журнале: признак
  «контакт» по книге номеров, а не по ссылке из кэша системного журнала;
- шапка меню долгого нажатия — в цвете темы (`secondaryContainer`),
  настройка «Цветная шапка меню» включена по умолчанию.

Замеры (прогон 06.10, сборка 1.3.5): холодный запуск 231 мс (−3,3%
к базе), тёплый −7%, карточка −10%, клавиатура −15%, память +1,7%.
Правки 06.10 путь запуска не трогают — повторный прогон не нужен.

## Клавиатура и строка номера — в стиле приложения (07.10.2026)

Автор: «клавиатура как из другого приложения, UI сильно отличается»;
отдельно — строка ввода номера. Что выбивалось и что стало:

| Было | Стало |
|---|---|
| Клавиши — прямоугольные плиты со скруглением 20 dp | Пилюли (`OgnelissShapeTokens.dialKey` = 50%) — как кнопки нижней панели и «Завершить» |
| Цифра слева, буквы столбиком справа | Цифра крупно по центру, под ней строка: буквы языка, рядом мельче латиница; у «1», «*», «#» строка пустая — цифры на одной линии; лёжа — только цифры |
| Номер / «Номер» прижаты к левому значку (центровка не работала в прокручиваемой колонке) | По центру строки; длинный номер прокручивается, как раньше |
| Подсказка «Номер» во всю высоту (`displaySmall`) | `headlineSmall`, цвет `outline` (~4,6 : 1 на белом) |
| Кнопки SIM без номера — системный серый | Тоновые зелёные: фон 16% `CallGreen`, подпись и значок зелёные |

Строка номера **оставлена на белой подложке** (теперь пилюлей, как
клавиши): без неё подсказка и граница на панели почти пропадают
(контраст ~1,3 : 1 — разбор 1.1.2 в `NumberDisplay`). Прерванная попытка
её убрать отменена.

## Что проверить на телефоне

1. Журнал: у контактов без фото — буквы, в том числе у старых звонков;
   у незнакомых номеров — серый значок.
2. Меню долгого нажатия: шапка в цвете темы — светлая, тёмная, AMOLED.
3. Клавиатура: клавиши-пилюли, цифра по центру, буквы под ней;
   в светлой, тёмной, AMOLED и в крупном режиме; лёжа — только цифры.
4. Строка номера: «Номер» по центру и мельче; набранный номер — по центру,
   длинный прокручивается; вставка, «добавить контакт», стирание — на месте.
5. Кнопки SIM: без номера — бледно-зелёные, с номером — зелёные.
6. Остальное — раздел «Что проверить на телефоне» в `RELEASE_NOTES_1.3.5.md`.
