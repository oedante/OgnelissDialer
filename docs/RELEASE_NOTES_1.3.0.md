Найдено пользователем 30.09.2026: «Очистить журнал» стирал весь журнал
сразу, без вопроса. Окно подтверждения потерялось в 1.2.1, когда меню

  и здесь, и в системном журнале телефона), что остаётся (заметки,

- **Удаление свайпом** («Удалить из журнала» как действие свайпа) — тоже
  с подтверждением: свайп легко сделать случайно, запись удаляется
  из системного журнала навсегда. Окно — в `RootScreen` (`deleteRequest`).
- **Закреплённые карточки при пустом журнале** — показываются. Раньше
  раздел закреплённых выводился только при непустом журнале: после
  очистки закреплённые пропадали до первого нового звонка.

## 2. Обои рабочего стола как фон

Настройки → Оформление: **«Обои как фон»**, **«Приглушение обоев»**
(0, 20, 35, 50, 70, 85 %; по умолчанию 35), **«Размытие обоев»**
(без размытия, 10, 20, 35, 50, 80 px; по умолчанию 20). Сама настройка
по умолчанию выключена — вид приложения сам не меняется.

Устройство — `ui/theme/WallpaperBackground.kt`:

- **Картинку обоев не читаем** — с Android 13–14 это требует закрытых
  разрешений. Система сама рисует обои под окном (`FLAG_SHOW_WALLPAPER`),
  окно прозрачное. Разрешений не нужно, живые обои тоже работают.
- **Размытие** — `setBackgroundBlurRadius`, Android 12+. Если система
  размытие выключила (энергосбережение, часть прошивок), обои видны
  чёткими, приглушение остаётся. На Android 8–11 — только приглушение.
- **Приглушение** — слой цвета фона темы поверх обоев: в тёмной теме —
  затемнение, в светлой — осветление. Всегда чёрный слой сделал бы
  тёмный текст светлой темы нечитаемым.
- **Непрозрачны** панели, кнопки, карточки журнала, окна и шторки — они
  на surface-цветах; прозрачен только фон экранов (`background`).
- **Не используется** в темах AMOLED и «Высокий контраст» и на экране
  вызова.

## 3. Имя на обложке карточки — выше

Имя лежало на самой границе обложки (4 dp от края) — теперь 16 dp.

## Что проверить на телефоне

1. **«Очистить журнал»** — спрашивает подтверждение; «Отмена» ничего
   не удаляет. После очистки закреплённые карточки на месте.
2. **Удаление свайпом** — спрашивает подтверждение.
3. **Обои как фон** — включить: под журналом обои, панели и карточки
   непрозрачные. Приглушение 0 → 85 % — меняется сразу; размытие
   0 → 80 px — меняется (Android 12+). В тёмной теме — затемнение,
   в светлой — осветление. Тема AMOLED — обоев нет. Выключить — вид
   как раньше.
4. **Карточка с фото** — имя не на самой границе обложки.

⚠️ Размытие через `setBackgroundBlurRadius` для окна с обоями под ним
на реальном телефоне не проверено. Если обои видны, но не размываются
(при включённом размытии в системе), — сообщить: возможен другой путь
(`FLAG_BLUR_BEHIND`).
