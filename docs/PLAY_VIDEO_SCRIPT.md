# Сценарий видео для Declared Permissions Form

Google требует видеодемонстрацию использования разрешений `CALL_LOG`
и `PHONE`. Это самый долгий этап публикации, и переснимать дорого —
лучше сделать правильно с первого раза.

## Требования Google

- Видео на **YouTube** (можно «по ссылке», не публичное)
- Показать **реальное** приложение на устройстве, не макеты
- Продемонстрировать **каждое** заявленное разрешение в работе
- Речь или субтитры на английском

## Что показать и в каком порядке

Длительность 2–3 минуты. Дольше не нужно: ревьюер смотрит десятки таких.

### 1. Приложение — диалер по умолчанию (0:00–0:25)
Открыть системные настройки → Приложения по умолчанию → Телефон →
выбрать Ogneliss. **Это ключевой кадр:** он обосновывает право
на все остальные разрешения.

### 2. `CALL_PHONE` — исходящий вызов (0:25–0:50)
Набрать номер на клавиатуре, нажать вызов, показать экран разговора,
завершить.

### 3. `READ_CALL_LOG` — журнал (0:50–1:20)
Показать список вызовов с именами, датами, счётчиками. Проговорить:
журнал читается из системного провайдера Android, собственная копия
не создаётся.

### 4. `WRITE_CALL_LOG` — удаление (1:20–1:35)
Удалить одну запись по команде пользователя. Подчеркнуть: запись
удаляется **только** по явному действию.

### 5. `READ_CONTACTS` — T9-поиск (1:35–2:00)
Набрать несколько цифр, показать, как находится контакт по имени.
Это наглядно объясняет, зачем диалеру контакты.

### 6. `ANSWER_PHONE_CALLS` — входящий (2:00–2:20)
Принять звонок с другого телефона, ответить кнопкой в приложении.

### 7. Приватность (2:20–2:40)
Открыть системные сведения о приложении → Разрешения, показать,
что **разрешения на доступ в интернет нет**. Затем экран
«О приложении» с тем же утверждением.

Этот кадр стоит отдельного внимания: он снимает большую часть вопросов
о том, что происходит с журналом вызовов и контактами.

## Текст для поля обоснования

> Ogneliss Dialer is a phone dialer application. It requests the
> CALL_LOG and PHONE permission groups because it functions as the
> user's default phone app, providing dialing, call management,
> call history and T9 contact search.
>
> All data is processed locally on the device. The application does not
> declare the INTERNET permission and is therefore technically unable to
> transmit any data. This can be verified in the app's permission list.

## Чего не делать

- Не снимать эмулятор: на нём нет реальной телефонии, и это видно
- Не показывать чужие номера и имена без размытия
- Не монтировать рывками: ревьюер должен успевать читать экран
