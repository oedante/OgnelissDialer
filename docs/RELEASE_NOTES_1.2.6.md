Миграций базы нет. Новых разрешений и зависимостей нет.

## Коротко: что изменилось относительно 1.2.5

- Панель свайпа из нескольких действий: у каждой кнопки свой значок,
  цвет и название (были одинаковыми, с номером под значком).
- Мессенджер из свайпа открывается на номере, где контакт им пользуется.
- В «Написать» у Telegram больше не показывается внутренний ID вместо номера.
- Карточка: имя на обложке внизу; без фото — сразу под строкой заголовка.

## Подробно: по проверке 1.2.5 на телефоне (30.09.2026)

**Кнопки панели свайпа были одинаковыми.** Первая версия брала первую
кнопку из «панели по номерам» каждого действия — а такие кнопки рассчитаны
на выбор номера: общий синий цвет, общий значок сообщения, подпись — номер.
SMS, Telegram и WhatsApp выглядели одинаково, под значком стоял номер.
Теперь у каждого действия своя кнопка: значок и цвет — как в настройках
свайпа, подпись — название действия. Заодно исправлено: в панели
по номерам все мессенджеры открывали WhatsApp.

**Мессенджер из свайпа открывался не на том номере** — на номере строки
журнала, а это мог быть городской номер или номер без этого мессенджера.
Теперь свайп открывает мессенджер так же, как «Написать» в карточке: через
телефонную книгу, на номере, где мессенджер у контакта есть. Номера нет
в контактах — по номеру, как было.

**У Telegram в «Написать» показывался «странный номер».** Это был
внутренний ID пользователя Telegram из строки книги. Номер для Telegram
теперь берётся только из подписи строки («Написать +7 910 …»).

**Большой зазор над именем в карточке.** С фото имя теперь на обложке,
внизу — на её растворённой в фоне части, обычным цветом текста (читается
в обеих темах). Без фото — сразу под строкой заголовка, без лишнего
отступа.

### Что проверить глазами

1. **Панель свайпа из трёх действий** — у каждой кнопки свой значок, цвет
   и название, номера под значками нет.
2. **Свайп «Telegram»/«WhatsApp»** по контакту с несколькими номерами —
   чат открывается на номере, где мессенджер есть.
3. **«Написать» у контакта с Telegram** — под строкой Telegram номер или
   ничего, но не длинный ID.
4. **Карточка** — с фото имя на обложке внизу, читается в обеих темах;
   без фото — сразу под строкой заголовка.
