# Ogneliss Dialer 2.0.0 (54) — сообщения

> Номер поднят автором до 2.0.0 (05.11.2026): диалер стал ещё и приложением
> сообщений. Ушла в закрытое тестирование 06.11.2026; в общий доступ
> выходит 2.0.1 (55) — `docs/RELEASE_NOTES_2.0.1.md`.

## Что нового

**SMS и MMS в диалере — по выбору человека.**

- **Писать SMS в диалере** (Настройки → Журнал → Сообщения). Кнопки
  «Написать» в журнале, карточке, свайпах и выборе SIM открывают
  переписку здесь. Это доступно, когда диалер — телефон по умолчанию.
  Выключено — открывается приложение сообщений, как раньше, без окна
  выбора.
- **Приложение SMS по умолчанию** — по желанию:
  - история переписки;
  - приём SMS и MMS;
  - уведомления с ответом прямо из шторки;
  - «ответить сообщением» на входящий вызов;
  - отправка картинок (MMS, до трёх, сжатие до ~280 КБ).
- **Один журнал**: SMS и MMS одной лентой с вызовами. В фильтре журнала
  есть выбор «Вызовы и сообщения / Вызовы / Сообщения». В строке:
  - текст последнего сообщения, непрочитанное темнее;
  - не отправленное — красным, облачко вместо стрелки.

  Свайпы работают как у вызовов. Касание строки, где последнее событие —
  сообщение, открывает переписку.
- **Коды подтверждения — на устройстве.**
  - Код ищется в тексте только рядом со словом «код»/«пароль»/«code»…
    Суммы, маска карты, даты и номера телефонов отсекаются.
  - В уведомлении появляется кнопка «Копировать 482913».
  - В переписке под таким сообщением — чип с кодом.
  - Код кладётся в буфер с пометкой «секретно»: Android 13+ не покажет
    его в превью. Клавиатура предложит вставить его одним касанием.
- **Копирование из сообщения** — долгое нажатие:
  - текст;
  - код;
  - номер телефона из текста (до трёх);
  - выделить любую часть текста;
  - повторить неотправленное;
  - удалить.
- **Отчёт о доставке** — переключатель, по умолчанию выключен. Часть
  операторов берёт за него плату.

## Работает без настройки — проверка на прошивках

Подробно — `docs/OEM_COMPAT.md`, раздел «2.0.0».

- **APK из файла на Android 15+.** Роли «Телефон» и «SMS» закрыты
  «ограниченными настройками». После отказа приложение показывает, куда
  нажать, и одной кнопкой открывает «О приложении».
- **Окно роли не показалось** — подсказка и «Приложения по умолчанию».
- **Роль SMS выдана** — сразу запрос уведомлений. На прошивках
  с автозапуском — одна подсказка в переписке.
- **Две SIM без карты SMS по умолчанию** — карта выбирается сама и видна
  в строке ввода.
- **Экран блокировки:**
  - «Новое сообщение» без текста, если содержимое скрыто;
  - «Копировать код» — после разблокировки.
- **«Разрешения»** — строка «Приложение SMS по умолчанию».

## Чего нет и почему

- **Автовставки кода в поля других приложений.** Её делает служба
  автозаполнения или клавиатура (Gboard, «Автозаполнение Google», Samsung
  Pass): они получают SMS сами, и с диалером в роли SMS это продолжает
  работать. Стать службой автозаполнения можно, но тогда она заменит
  менеджер паролей — в системе такая служба одна.
- **RCS** сторонним приложениям недоступен — остаётся в «Сообщениях».
- **Групповые MMS**: переписка открывается с первым адресатом.

## Конфиденциальность

- Разрешения `INTERNET` по-прежнему нет. MMS передаёт система, а не
  приложение.
- Политика конфиденциальности — версия 1.2 (ru/en в приложении, 4 языка
  на сайте).
- Play: раздел 1а в PLAY_COMPLIANCE.md (Permissions Declaration Form,
  видео).

## Проверить на устройстве

1. Не SMS по умолчанию:
   - «Написать» из журнала → переписка, плашка «Сделать»;
   - отправка SMS с запросом SEND_SMS;
   - отправленное видно до выхода.
2. «Сделать» → системное окно роли.
3. После роли:
   - история появилась;
   - входящее → уведомление, ответ из шторки;
   - «Прочитано»;
   - SMS с кодом → «Копировать …» в шторке и чип в переписке.
4. MMS:
   - картинка туда (две SIM: выбор карты в строке ввода);
   - входящее MMS скачивается само.
5. Журнал:
   - SMS и вызовы вперемешку по времени;
   - фильтр «Сообщения»;
   - свайп удаления строки с SMS;
   - касание открывает переписку.
6. Отказ от роли (выбрать другое приложение SMS): SMS пропадают из
   журнала, переписка только на отправку.
7. Входящий вызов → «Ответить сообщением» → SMS уходит.
