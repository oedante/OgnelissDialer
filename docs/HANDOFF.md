# Ogneliss Dialer — передача в новый чат

Документ для продолжения работы в новом чате. Приложить к первому
сообщению вместе с архивом проекта.

## Что это

Android-диалер (замена системного) — `com.ogneliss.dialer`, бесплатная,
без рекламы и **без доступа в интернет** (это принцип, проверяется
`scripts/check_no_internet.sh`). В Google Play, сайт — ogneliss.ru/dialer.
С 1.5.7 код открыт: Apache 2.0 + NOTICE, github.com/oedante/OgnelissDialer;
название и значок — за автором (`TRADEMARKS.md`).
Автор — Олег (oedante@gmail.com), отзывы — Google Play и форум.

## Как работаем (сложившиеся правила)

- Общение — по-русски. Комментарии в коде — по-русски, с причиной
  решения («было — стало — почему»), с версией и датой находки.
- Перед упаковкой каждый раз: `python3 scripts/prebuild_check.py`,
  `scripts/kotlin_syntax_check.sh` (kotlinc в окружении Claude),
  `python3 scripts/audit.py`, `python3 scripts/import_check.py` — все
  без замечаний. Синтаксис ≠ компиляция: импорты символов проекта
  проверяет только `import_check.py` (и `private` из чужого файла) (добавлен после сбоя сборки
  01.10.2026 — 17 файлов без импорта `suspendRunCatching`).
- Строки интерфейса — в 4 языках вручную (en, ru, de, fr); остальные
  44 — автоперевод Google Play (не добавлять туда наши 4!). Названия
  марок — `translatable="false"`.
- Строки для журнала разработчика — не в пакетах `ui/` и `call/`
  (аудит считает их строками интерфейса): общие — в `log/`.
- Номера в журнале приложения — только через `Logger.mask` / `maskKey`.
- Подписки на потоки в Compose — `collectAsStateWithLifecycle`, не `collectAsState`.
- Значок — из `store/source/icon_master_1024.png` скриптами `make_icons.py`,
  `make_monochrome.py`, `build_feature_graphic.py` (порядок — `scripts/README.md`);
  файлы значка руками не править.
- Сайт с 11.10.2026 собирается в репозитории Mail (`site/build_site.py`,
  языки по папкам `ru/`, `de/`, `fr/`); `docs/www` здесь — копия, из неё
  берётся `app-icon.png`. Исключение — 1.5.7: документы Dialer (`eula`,
  `terms`, `privacy`, `licenses`) обновлены здесь под лицензию Apache 2.0;
  их нужно перенести в многоязычные исходники сборщика Mail. До переноса
  на сервер выкладываются готовые страницы `ogneliss-site-dialer-1.5.7.zip`.
- Интерфейс — по `docs/DESIGN_SYSTEM.md`; отступы — `Space.*`, не числами.
- Верх экрана (1.5.8): корень отступает только по бокам и снизу — каждый экран
  сам учитывает строку состояния (`ScreenScaffold` или `Scaffold` с
  `contentWindowInsets = WindowInsets.safeDrawing`). Новый экран без Scaffold
  окажется под часами.
- Большие функции экранов делим при правке блока — выносим его в `*Parts.kt`.
- Иконки — только `OgnelissIcons` (Material Symbols Rounded). Новая — строка
  в `scripts/icons_manifest.json` + `python scripts/build_icons.py`;
  `androidx.compose.material.icons` не подключать.
- Подписи, которые могут не поместиться, — `FitText` (уменьшение
  шрифта вместо переноса посреди слова).
- Сайт `docs/www` — для двух приложений: Dialer в корне каталога, Mail в `mail/`.
  Страницы Mail не править вручную — их собирает `build_mail_pages.py`
  в репозитории Mail.
- Экстренные номера — `util/EmergencyNumbers`; проверять кодом,
  не вызовом.
- В корутинах — `suspendRunCatching` вместо `runCatching` (отмена
  не глотается); в обычном коде — `runCatching`.
- Каждый выпуск: `docs/RELEASE_NOTES_x.y.z.md` (сводка, разделы
  с причинами, проверки) и `store/whats_new_x.y.z.txt` — «Что нового»
  для **27 языков** в формате меток `<ru-RU>…</ru-RU>`, до 500
  знаков на язык. Порядок — как в прошлом файле (ru-RU, ar, cs-CZ,
  da-DK, de-DE, en-US, es-ES, fi-FI, fr-FR, hi-IN, hu-HU, id,
  it-IT, iw-IL, ja-JP, ko-KR, nl-NL, no-NO, pl-PL, pt-BR, ro, sk, sv-SE,
  th, tr-TR, vi, zh-CN); es-419 в файлах не бывает с 1.3.5.
- Код открыт (1.5.7): в комментариях, тестах и макетах — только
  вымышленные номера, имена и фото; перед отправкой в GitHub —
  `python3 scripts/oss_audit.py`.
- Версию поднимаем, когда предыдущая ушла в консоль; правки после
  публикации — в файл изменений следующей версии.
- Архив в выдаче один, итоговый: `OgnelissDialer_x_y_z.zip`
  (`_wip` — пока выпуск собирается).

## Принятые решения (не пересматривать без причины)

- Мелодию звонка играет система (мелодии контактов, «Не беспокоить»).
- Редактирование контактов — системное приложение «Контакты».
- Видеозвонки — отложены до просьб в отзывах (`ROADMAP.md`).
- Флагов в выборе языка нет (язык ≠ страна).
- Зелёный цвет — только звонок; управление — основной (синий).
- Меню — шторками с группами (`SheetGroup`), не выпадающими меню;
  действия с записью по долгому нажатию — карточками (`ActionCards`, 1.5.7).
- Удаление из журнала — с «Отменить», без окна подтверждения для одной
  записи (`deleteGroupsWithUndo`, 1.5.7).
- Номер в карточке контакта — касание звонит, справа только SMS,
  остальное — долгим нажатием (1.5.8). Ответ на вызов по умолчанию —
  касанием; сдвиг — по выбору (1.5.8).
