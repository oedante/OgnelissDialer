## 1. Экран вызова без панели и на ровном фоне

Было (1.6.0–1.6.1): панель под кнопками убиралась только над живым фоном.
Если живой фон выключен — а на AMOLED его часто выключают, — под кнопками
стояла серая панель, на чёрном экране она выглядела заплаткой.

Стало: панели нет и на ровном фоне, во всех темах, кроме высококонтрастной.

- цвет страницы — до краёв экрана, под строкой состояния и навигацией
  тоже (`PlainCallBackground`): на AMOLED — сплошной чёрный, без полосы
  цвета окна (#121316) сверху и снизу;
- кнопки, дорожка ответа сдвигом, тоновый набор, второй вызов и
  конференция — с тем же тонким кольцом и тенью, что над живым фоном
  (`ambientEdge`): белые кнопки на светлом ровном фоне не теряются;
- панель осталась под **фото на весь экран** (без неё на снимке терялись
  бы подписи) и в **высококонтрастной теме** (там границы важнее вида);
- псевдозвонок — так же.

## 2. Имена контактов: «Фамилия Имя» и сортировка по фамилии

Настройки → Оформление → группа **«Имена контактов»**, два пункта, как
в системных «Контактах»:

- **«Как показывать имя»** — «Имя Фамилия» (как было) или «Фамилия Имя»;
- **«Сортировка контактов»** — по имени (как было) или по фамилии.

Пункты независимы: можно показывать «Андрей Петров», а искать его под «П».
Буква раздела — по тому, по чему отсортировано. Поиск по настройкам
находит их по словам «фамилия», «сортировка», «порядок».

**Откуда «Фамилия Имя».** Не из разбора строки по пробелу — «Сервис
доставки» стал бы «доставки Сервис». Книга хранит имя по частям (имя,
отчество, фамилия) и сама собирает вторую форму
(`DISPLAY_NAME_ALTERNATIVE`). Её и берём; запятую после фамилии
(«Petrov, Andrey») убираем. У записей без частей — организация, почта,
одно слово — ничего не переставляется. Так же ведут себя системные
«Контакты» при «Сначала фамилия».

⚠️ Если имя записано одной строкой (часто у контактов с SIM), книга
делит его сама: последнее слово — фамилия. «Андрей Петров» → «Петров
Андрей», как надо. Но у того, кто уже пишет «Петров Андрей» одной
строкой, «Фамилия Имя» переставит наоборот — так же поступают и
системные «Контакты». Таким людям настройка не нужна: у них имена уже
в нужном порядке, а «Сортировка → по имени» и есть сортировка по
фамилии.

**Где действует «Как показывать имя»:**

- список контактов и избранные — имя, буквы в аватаре («Петров Андрей» →
  «ПА»), подпись для TalkBack;
- журнал — имя в строке. Имя в журнале пишет система; переставляем его,
  только если это имя того же контакта: у номера, записанного у двоих,
  чужое имя не появится;
- карточка абонента — заголовок;
- найденные контакты в поиске;
- экран вызова и псевдозвонок — имя, которое дала система, переставляется
  после короткого запроса к книге (`ContactsRepository.familyFirstName`);
  входящий его не ждёт.

**Где не действует:** уведомления о пропущенных и о входящем (имя в них
даёт система), подписи заметок и напоминаний, сохранённые раньше,
выгрузки. В данных остаётся основная форма: на ней держатся правило
«при двух контактах на номер — первый по алфавиту», сопоставление
с журналом и индекс T9.

**Сортировка по фамилии** — по правилам языка телефона, как и порядок
книги (по-русски: кириллица, затем латиница; «ё» рядом с «е»).

**База 6 → 7.** В кэш книги добавлен столбец `nameAlt` — иначе при запуске,
до чтения книги, журнал секунду показывал бы «Имя Фамилия», а потом
переставлял слова. Миграция — один `ALTER TABLE … ADD COLUMN` с пустым
значением, другие таблицы не трогает; тест — `MigrationTest`
(`кэшКнигиПолучаетИмяФамилияИмя`).

## 3. Редактирование контактов — без изменений

Отдельной формы редактирования внутри приложения нет — это решение,
а не пропуск (разбор — `ContactEditor.kt`): контакт в Android — склейка
записей нескольких аккаунтов (Google, телефон, SIM, мессенджеры), часть
полей теряется при синхронизации, часть записей только для чтения.
Ошибка здесь портит данные, которыми пользуются другие приложения.

Изменить контакт можно и сейчас — откроется форма системных «Контактов»,
после сохранения возврат в приложение:

- долгое нажатие на запись журнала или контакт → **«Изменить»**;
- карточка абонента → «Ещё» → **«Редактировать контакт»**.

## 4. Сборка

Предупреждение Gradle у автора (23.10): `'fun srcDir(srcDir: Any): Any' is
deprecated. Use directories mutable set instead` — `app/build.gradle.kts`,
схемы Room для тестов миграций. Каталог теперь добавляется в набор
`directories` (AGP 9.4): `assets.directories += "$projectDir/schemas"`.

## Что проверить на телефоне

1. Тема AMOLED, «Живой фон» выключен: входящий и разговор — фон сплошной
   чёрный до краёв, панели под кнопками нет, кнопки с тонким кольцом.
2. То же в светлой и тёмной теме: белые / тёмные кнопки видны на ровном
   фоне; тоновый набор, второй вызов, дорожка сдвига — с кольцом.
3. Фото на весь экран — панель есть, как раньше. Высокий контраст — панель есть.
4. Псевдозвонок с выключенным живым фоном — без панели.
5. Настройки → Оформление → «Имена контактов»: «Фамилия Имя» — в контактах,
   журнале, карточке, поиске, на экране вызова «Петров Андрей»; у
   «Сервис доставки» и других записей одной строкой — без изменений.
6. «Сортировка контактов» → «По фамилии»: буквы разделов по фамилии,
   «Ё» под «Е», латиница после кириллицы, цифры в «#» в начале.
   Вместе с «Имя Фамилия» — «Андрей Петров» под «П».
7. Переключить «Как показывать имя» — журнал перестраивается сразу,
   без перезапуска. Перезапустить приложение — имена сразу в выбранной
   форме, без перестановки через секунду (кэш).
8. Номер записан у двух контактов: в журнале имя того, кого показывала
   система, только в другой форме.
9. Обновление поверх 1.6.1 — заметки, напоминания, блокировки на месте
   (миграция 6 → 7).
10. TalkBack: строки журнала и контактов читают имя в выбранной форме.

## Команды

Архив — **в чистую папку**, перенося `keystore.properties`,
`local.properties` и **`app/schemas/*.json`** (схемы базы прошлых
версий: в архиве их нет, без них не запустится тест миграций). После
сборки появится `app/schemas/…/7.json` — его закоммитить.

```powershell
./gradlew assembleDebug
./gradlew testDebugUnitTest
./gradlew connectedDebugAndroidTest   # тест миграций 6 → 7, телефон по USB
./gradlew bundleRelease
```

Репозиторий: коммит поверх 1.6.1 (или публикация сразу с 1.6.2 по
`docs/OPEN_SOURCE.md`), тег `v1.6.2`. Перед отправкой —
`python scripts/oss_audit.py`.
