# Доступность — Ogneliss Dialer

Диалером пользуются в том числе пожилые люди и люди с нарушениями зрения
и моторики. Для этой категории приложений доступность — не галочка,
а условие работоспособности.

## Что уже сделано

| Требование | Реализация |
|---|---|
| Зоны нажатия ≥ 48 dp | `Dimens.MIN_TOUCH_TARGET`, применён во всех строках настроек и клавишах |
| Масштабирование шрифта | Вся типографика в `sp`, не в `dp` |
| Контраст ≥ 4.5:1 | В светлой теме используется затемнённый `#C77E00` вместо `#FAA814` |
| Озвучивание строк целиком | `mergeDescendants` в списках и настройках |
| Состояние переключателей | `stateDescription` + `toggleableState` |
| Заголовки для навигации | `heading()` у названий групп |
| Радиокнопки | `selectable` на всей строке, `role = RadioButton` |
| Кнопка вызова и отбоя | 56 dp, разнесены на 40 dp |
| Датчик приближения | Экран гаснет у уха — защита от нажатий щекой |
| Крупные кнопки | Настройка «Крупные кнопки» в разделе Оформление |
| Подписи действий (1.5.8) | Вместо общего «нажмите дважды и удерживайте» — что случится: строки журнала и контактов — «Открыть карточку» / «Действия» (в режиме выбора — общие: нажатие выбирает); номер в карточке — «Позвонить» / «Действия с номером» (`combinedClickable` с `onClickLabel`, `onLongClickLabel`) |
| Число новых на «Наверх» (1.5.8) | Описание кнопки целиком — «Наверх, 2 новых вызова»; надпись внутри не читается второй раз |
| Отсчёт в сообщении (1.5.8) | Кольцо и секунды скрыты от чтения: сообщение объявляется один раз. Срок — с учётом «Времени на выполнение действия» |
| Ответ сдвигом (1.5.8) | С TalkBack — обычные кнопки (включили во время звонка — сразу); для Switch Access и голоса — действия «Ответить» и «Отклонить» у ручки |
| Свёрнутая группа настроек (1.5.8) | «Дополнительно» — кнопка с состоянием «развёрнуто» / «свёрнуто»; изменённый пункт — слово «изменено» в описании строки |
| Переключатель «журнал \| контакты» (1.6.0) | Одна кнопка: имя — открытый список («Журнал»), действие касания — «Перейти: Контакты», долгого нажатия — «Все разделы». Список разделов — кнопки с названиями, текущий отмечен как выбранный; «Назад» закрывает |
| Поиск в панели (1.6.0) | Поле получает фокус и клавиатуру сразу; стрелка — «Закрыть поиск», крестик — «Очистить поиск» |
| «Вопросы и ответы» (1.6.0) | Вопрос — кнопка с состоянием «развёрнуто» / «свёрнуто»; ответ читается обычным текстом; кнопки под ответом — со своими названиями («Ответ на вызов», «Написать письмо») |
| Экран вызова без подложки (1.6.0) | Кнопки на живом фоне — с кольцом и тенью: граница видна при любом цвете фона под ними, не только по контрасту значка |

## Принципы, которых придерживаемся

**Нажатие ловит вся строка, а не элемент управления.** Попасть в `Switch`
шириной 32 dp сложно; в строку высотой 56 dp — легко.

**Декоративные иконки не озвучиваются.** `contentDescription = null`
у иконок категорий и аватаров: смысл несёт соседний текст, дублирование
удваивает время прослушивания.

**Клавиша читается как «Клавиша 5», а не «5 JKL МНОП».** Перечисление букв
на слух бесполезно.

**Опасные действия объясняются конкретно.** Не «вы уверены?», а «курьеры,
поликлиники и школы перестанут до вас дозваниваться».

## Что проверяется автоматически

`AccessibilityTest` в `androidTest` ломает сборку при нарушении:

| Проверка | Почему автотестом, а не глазами |
|---|---|
| Зоны нажатия ≥ 48 dp | Кнопку легко ужать ради вёрстки и не заметить |
| Клавиши озвучиваются как «Клавиша 5» | Описание легко случайно заменить на весь текст клавиши |
| Кнопки вызова называют SIM | Иначе две одинаковые «кнопка вызова» |
| Нет кнопок без описания | Добавить иконку без описания — вопрос одной строки |

Ручной чек-лист от потери доступности не спасает: его проходят перед
релизом, а ломается всё в промежутке. Тест сообщает сразу.

Запуск: `./gradlew connectedDebugAndroidTest`

## Что осталось проверить вручную

- [ ] Полный прогон TalkBack по сценариям: набор, приём вызова, настройки
  (с 1.5.8 — ещё карточка контакта: строка номера, карточки номера;
  «Дополнительно» в настройках; с 1.6.0 — переключатель и список разделов,
  поиск в панели, «Вопросы и ответы» и кнопки под ответами)
- [ ] Системный шрифт 200% — все экраны без обрезки текста
- [ ] Режим увеличения экрана (Magnification)
- [ ] Switch Access — управление без касаний
- [ ] Проверка контраста всех состояний, включая disabled
- [ ] Инверсия цветов
- [ ] Работа одной рукой на экране 6.7"
- [ ] Проверка с включённой опцией «Убрать анимацию»

## Как тестировать

```
Настройки Android → Специальные возможности → TalkBack
Настройки Android → Экран → Размер шрифта → максимальный
Настройки разработчика → Показывать границы макета (проверка зон нажатия)
```

Инструмент Accessibility Scanner из Play Store автоматически находит
малые зоны нажатия и низкий контраст — прогонять перед каждым релизом.
