На телефоне не проверялось.

## 1. SMS: папка «Заблокированные»

- Переписки с номерами из чёрного списка (правила блокировки, маски; «Разрешить» важнее,
  как у вызовов) — только в новой папке «Заблокированные» (`SmsFolder.BLOCKED`,
  `SmsFolders.isBlocked`). Из «Все», остальных папок и поиска они убраны; число
  непрочитанных у папки не показывается. Папка — последней в меню; порядок и показ —
  «Настроить папки», как у остальных.

## 2. Где сохранить контакт — аккаунты DAVx⁵ и других синхронизаций

- Причина: с Android 11 приложения синхронизации и владельцы аккаунтов (DAVx⁵, почта,
  Xiaomi) без объявления в манифесте не видны: `getSyncAdapterTypes`
  и `AccountManager.authenticatorTypes` их не отдают — их аккаунты считались «Телефоном»
  и сливались в одну строку. Стало: `<queries>` для `android.content.SyncAdapter`
  и `android.accounts.AccountAuthenticator`; тип с приложением-владельцем — свой источник.

## 3. Размер текста SMS

- Настройки → SMS → «Размер текста SMS» (ползунок 80–160 %): только текст сообщений
  в переписке, поверх размера шрифта приложения; строки растут вместе с кеглем.

## 4. Своя картинка у неизвестного номера с заметкой

- Было: у номера не из книги с заметкой — всегда значок заметки «i», своя картинка
  «Неизвестные номера» (2.8.0) не показывалась. Стало: если картинка задана и показывается
  в списках — картинка, а «i» — маленьким значком в углу.

## 5. Поиск в журнале

- Найденные записи журнала шли по дате звонка — без учёта совпадения и «Порядка
  результатов поиска». Стало (`ContactSearch.rankLog`): «По алфавиту» — по имени, без
  имени — в конце; остальное — сначала совпадение с начала имени, затем с начала слова
  (или номера), затем в середине слова и в заметке; внутри — «Частые» по числу звонков,
  «Недавние» и «По релевантности» — свежие выше.
- Поиск буквами учитывает «Порядок результатов» и для контактов (было — всегда
  по релевантности).

## 6. Ответ и сброс свайпом вверх и вниз

- Настройки → Вызовы → «Ответ на вызов» → «Свайпом вверх или вниз»: круглая ручка
  посередине, вверх — ответить, вниз — отклонить, срабатывает после 70 % пути, на пороге —
  вибрация (`VerticalSwipeToAnswer`). Лёжа (мало высоты) — сдвиг вбок, с TalkBack —
  кнопки, как у сдвига. Псевдозвонок — так же.
