# Выпуск релиза: по шагам

Инструкция под этот проект. Команды даны для Windows (PowerShell
или cmd) — на Linux и macOS вместо `gradlew.bat` пишите `./gradlew`.

Всё выполняется из корня проекта: `D:\VS\OgnelissDialer\ogneliss-dialer`

---

## Шаг 0. Подключить телефон

Нужен для шагов 2 и 5. На телефоне: **Настройки → О телефоне** →
семь раз нажать «Номер сборки» → появится раздел «Для разработчиков» →
включить **Отладку по USB**.

```
adb devices
```

Должно вывести устройство со статусом `device`. Если `unauthorized` —
на телефоне появится запрос, разрешите.

---

## Шаг 1. Первая сборка debug и схемы Room

```
gradlew.bat clean
gradlew.bat :app:assembleDebug
```

После успешной сборки:

```
dir app\schemas\com.ogneliss.dialer.data.db.AppDatabase
```

Должны появиться `1.json`, `2.json`, `3.json`.

**Закоммитить обязательно:**

```
git add app/schemas
git commit -m "Схемы Room: версии 1-3"
```

> **Зачем.** Room сравнивает схему при следующей миграции. Без файлов
> сравнивать не с чем, проверка молча пропускается — и ошибка вылезет
> уже у пользователей при обновлении, когда откатиться нельзя.

---

## Шаг 2. Проверить debug на телефоне

```
gradlew.bat :app:installDebug
```

Проверьте: журнал загружается, звонок проходит, контакты видны.
Если что-то не так — дальше идти незачем.

## Шаг 3. Ключ подписи

**Делается один раз в жизни приложения.** Если ключ уже есть —
пропустите.

```
keytool -genkey -v -keystore D:\keys\ogneliss-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias ogneliss
```

Спросит пароль и данные владельца. Создайте `keystore.properties`
в корне проекта:

```properties
storeFile=D:/keys/ogneliss-release.jks
storePassword=ваш_пароль
keyAlias=ogneliss
keyPassword=ваш_пароль
```

Файл уже в `.gitignore`.

> ⚠️ **Пароль и файл `.jks` запишите отдельно и сделайте копию.**
> Восстановить их нельзя. Потеряв ключ, вы не сможете выпустить
> обновление: Google Play не примет APK, подписанный другим ключом.
> Приложение придётся публиковать заново, с нуля, потеряв всех
> пользователей и отзывы.

## Шаг 4. Пробная сборка release

```
gradlew.bat :app:assembleRelease
```

Проверяет, что R8 отработал и ничего не сломал. Установите:

```
adb install -r app\build\outputs\apk\release\app-release.apk
```

**Две проверки, которые ловят ошибки, невидимые в debug:**

| Проверка | Если провалилась |
|---|---|
| Откройте настройки — значения на месте? | Обфускация задела имена enum: проверьте правило `valueOf` в `proguard-rules.pro` |
| Позвоните себе с другого телефона — входящий приходит? | R8 вырезал сервисы телефонии: проверьте `-keep class com.ogneliss.dialer.call` |

Заодно оцените плавность: она должна заметно отличаться от debug.

## Шаг 5. Baseline Profile

Даёт 20–30 % к скорости холодного старта. Телефон должен быть
подключён.

```
gradlew.bat :app:generateBaselineProfile
```

Займёт несколько минут: на телефоне прогонятся сценарии запуска
и прокрутки. Затем:

```
type app\src\main\baseline-prof.txt
```

Файл должен содержать сотни строк вида `Lcom/ogneliss/dialer/...`.
Если там только комментарии — профиль не сгенерировался, см. ниже.

**Закоммитить:**

```
git add app/src/main/baseline-prof.txt
git commit -m "Baseline Profile"
```

> **Если команда падает.** Модуль `:benchmark` требует устройства
> с разблокированным экраном и без блокировки. Попробуйте отключить
> блокировку экрана на время генерации. Если не выходит — релиз можно
> выпускать и без профиля, приложение работает, просто запускается
> медленнее.

## Шаг 6. Финальная сборка для Google Play

```
gradlew.bat clean
gradlew.bat :app:bundleRelease
```

Результат:

```
app\build\outputs\bundle\release\app-release.aab
```

> **Именно AAB, не APK.** Google Play принимает только App Bundle:
> он позволяет доставлять устройству нужную часть ресурсов вместо
> всех сразу.

`clean` перед сборкой обязателен: он гарантирует, что в сборку попал
свежий Baseline Profile, а не закэшированный старый.

## Шаг 7. Загрузка в Google Play Console

1. **Создать приложение** — если ещё не создано
2. **Закрытое тестирование** → загрузить `app-release.aab`
3. Заполнить обязательное:

| Раздел | Что указать |
|---|---|
| Политика конфиденциальности | `https://ogneliss.ru/dialer/privacy` |
| Веб-сайт | `https://ogneliss.ru/dialer/` |
| Эл. почта | `oedante@gmail.com` |
| Безопасность данных | **Данные не собираются и не передаются** |
| Возрастной рейтинг | Анкета IARC |
| Разрешения | Обосновать `READ_CALL_LOG` и роль диалера |

4. **Скриншоты:** 6–8 штук, ≥1080 px по короткой стороне

> ⚠️ **Снимайте вымышленные контакты.** Скриншот с настоящим именем
> и номером — утечка чужих данных, и Google Play такое отклоняет.

## Шаг 8. Закрытое тестирование

**Требуется 12 тестеров на 14 дней** для новых аккаунтов
разработчика.

Польза не только формальная: диалер ставят по умолчанию, и ошибка
на чужой прошивке означает пропущенные звонки у живого человека.
Мы уже видели, что nubia ведёт себя иначе — а есть Xiaomi, Samsung,
Honor.

**Что просить проверить у тестеров:**

- Установилось ли приложение диалером по умолчанию, и что для этого
  потребовалось
- Приходят ли входящие
- Определяется ли имя звонящего
- Работают ли свайпы

---

## Шаг 9. Открытый релиз

После 14 дней теста без критических замечаний — перевод в открытый
доступ.

Перед этим смените версию в `app/build.gradle.kts`:

```kotlin
versionCode = 2          // должен расти с каждой загрузкой
versionName = "1.0.0"    // убрать суффикс rc
```

> `versionCode` обязан увеличиваться с каждой загрузкой в Play.
> Загрузить сборку с прежним номером магазин откажется, а изменить
> номер уже загруженной нельзя.

```
gradlew.bat clean

```

## Если что-то пошло не так

**Сборка падает после `clean`.** Кэш Gradle:

```
gradlew.bat --stop
gradlew.bat clean build --refresh-dependencies
```

**Нужен подробный вывод ошибки:**

```
gradlew.bat :app:assembleRelease --stacktrace --info
```

**Посмотреть, что попало в сборку:**

```
gradlew.bat :app:assembleRelease -Pcompose.metrics=true
```

Отчёт о стабильности Compose появится в `app/build/compose_metrics/`.

**Замер плавности на устройстве:**

```
adb shell dumpsys gfxinfo com.ogneliss.dialer reset
```

Прокрутите журнал пять секунд, затем:

```
adb shell dumpsys gfxinfo com.ogneliss.dialer | findstr Janky
```

Норма — меньше 5 % janky кадров.
