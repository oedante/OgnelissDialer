## 1. Деление ViewModel и экранов — пересмотр по фактическим цифрам

Аудит называл `DialerViewModel` «3085 строк, 26 зависимостей». Подсчёт
без комментариев (в коде подробные «было / стало / почему»):

| Файл / функция | Строк всего | Строк кода |
|---|---|---|
| `DialerViewModel.kt` | 3040 | 1232 |
| самая крупная функция ViewModel — `doRefresh` | 422 | 101 |
| следующие: `rebuildRows`, `init`, `applyFilter` | 161 / 153 / 72 | 64 / 52 / 30 |
| функция `SubscriberScreen` | 2210 | 942 |
| функция `MainDialerScreen` | 1981 | 1026 |
| функция `InCallScreen` | 947 | 444 |

**Решение:**
- **ViewModel дальше не делится.** После выноса `ExportController`
  и `PinnedController` остаток связный, крупнейшая функция — 101 строка
  кода; оценка «~400 строк действий свайпа» была ошибочной (25 строк,
  опираются на `RevealActionFactory`). Риск переноса не окупится.
- **Функции экранов делятся при правке, а не отдельной операцией.**
  Они действительно большие (940–1030 строк кода в одной функции), но
  деление невидимо для пользователя, а перенос кусков с общим локальным
  состоянием рискован. Правило: когда правим блок экрана по делу — выносим
  его в отдельную функцию в `*Parts.kt`.

## 2. Холодный запуск — разбор по трассам Perfetto

В 1.3.4 холодный запуск без компиляции +13% (271 мс); перевод иконок дал
только 2%. Угадывать дальше не стали:

- `scripts/analyze_startup_trace.py` — по трассе Perfetto печатает время
  от старта процесса до первого кадра и на что его тратит главный поток:
  `bindApplication` (Application, Hilt), `activityStart`, первый
  `Choreographer#doFrame`, загрузка классов. Нужен `pip install perfetto`.
- `phone_check.ps1` сохраняет три трассы холодного запуска
  в `docs/baseline/traces/<метка>-cold/` — следующий прогон их не затрёт;
  каталог исключён из git (`.gitignore`).

## 3. Профиль запуска — со строками журнала

(Перенесено из 1.3.4, модуль замеров.) `benchmark/CallLogSeed` перед
съёмкой профиля заполняет журнал **эмулятора** 40 тестовыми звонками —
строки журнала, свайп и бросок попадут в профиль. Только эмулятор: вызов
из блока съёмки и проверка `Build.HARDWARE`.

## 4. Список контактов — один шаблон с журналом

Аудит: «разные шаблоны списков (контакты / журнал)». **Было:** каждый
контакт — отдельная карточка с промежутками даже внутри одной буквы.
**Стало** — как группа журнала: контакты одной буквы (и избранные) в одной
карточке, скругление у первой и последней строки, разделитель от начала
текста. `GroupPosition` — тот же, что у строки журнала.

## 5. Иконки в шторках — нейтральные

Аудит: «в шторках иконки нейтральные, цвет только у опасных пунктов».
Бирюзовая иконка «Записать заметку» (меню долгого нажатия) и «Заметки»
(меню «Ещё» журнала) — теперь нейтральные, как остальные. Бирюзовый
остался у панели заметки в карточке — там он и обозначает заметку.

## 6. Отступы вне шкалы — разобраны все 40

- **2 dp (13 мест)** — систематическое значение (межстрочные зазоры, поля
  плашек): новая ступень `Space.xxs`; правило 40 её знает.
- **20 dp в подсказке жестов (2)** — поле шторки: `FlowUi.sheetPadding`.
- Остальные — осознанные исключения с причинами в `DESIGN_SYSTEM.md`:
  6 dp — высота строк списков; 56/76 dp — геометрия разделителя; единичные
  точные подгонки. Вид не изменился ни в одном месте.

## 9. Карточка: «Ещё» вместо «Блока», «Блок» — в меню (предложение автора)

**Было:** «Блок» — в нижнем ряду справа, прямо над системной «Назад»: туда
палец попадает случайно; меню ⋮ — в верхней панели, далеко от пальца.
**Стало:** на месте «Блока» — «Ещё» (случайное нажатие лишь откроет
шторку); ⋮ вверху убран — меню одно. «Блок» — в меню последним, отдельной
группой: «Заблокировать номер» красным, «Разблокировать номер» основным
цветом; блокировка по маске — прежнее объяснение. Логика та же —
`onBlockAction`. Меню управляется снаружи (`open` / `onDismiss`).

## 10. Меню долгого нажатия: шапка по началу подписей

Скриншот автора: имя правее подписей пунктов. Расчёт 1.3.3 ставил центр
кружка 48 dp на колонку иконок — имя оказывалось на 80 dp, подписи — на 68.
Оба условия при 48 dp не выполнить. **Стало:** имя ровно на начале подписей,
зазор 8 dp, кружок 40 dp (48 в крупном режиме) — его центр снова на колонке
иконок. `RowAvatar(size = …)` — необязательный размер.

## 11. Цветная шапка меню записи — в цвете темы (по умолчанию вкл.)

Предложение автора — заливка шапки меню долгого нажатия (от верха шторки
до кнопок). Первый вариант брал преобладающий цвет фото контакта; автор
(06.10): «нравится идея, не нравятся рандомные цвета». **Стало:** цвет —
`secondaryContainer` темы, тот же оттенок, что у круглых кнопок меню;
есть в каждой теме, следует динамическому цвету. `primaryContainer`
не взят — на нём буквы контактов, кружок слился бы с шапкой. Цвет известен
сразу: ни расчёта, ни фоновой работы — нагрузки нет. Настройка
«Оформление» → «Цветная шапка меню» (`sheet_header_tint`), включена
по умолчанию. `PhotoTint` и его тест удалены.

## 12. Экран вызова: под системной навигацией — цвет панели

Скриншот автора (тёмная тема): под кнопками ◁ ○ □ просвечивало фото —

цвета панели высотой в системный отступ навигации; лёжа — нулевой высоты.
Псевдозвонок — так же.

## 14. Буквы в аватаре контакта (задача автора)

«Чтобы контакты отделять от незнакомых номеров» (образец — скриншот
контактов Ogneliss Mail). У контакта без фото — буквы на фоне
`primaryContainer`: первые буквы двух первых слов, начинающихся с буквы
(«Тестовый Контакт» → «ТК»), одна — если такое слово одно («Тест1» → «Т»);
слов с буквой нет — значок человека. Незнакомый номер — серый значок, как
раньше, **даже с именем из определителя**: в журнале имя передаётся только
при `contactId`. Буквы — 36% диаметра: растут с крупным режимом и шрифтом.
Пропущенный — прежняя подсветка. `util/Initials` + `InitialsTest` (4).
Везде, где аватар: журнал, контакты (теперь общий `RowAvatar` вместо
своей копии), меню записи, закреплённые без звонков.

## 16. Проверки

Правило 39 знает `remember` — его импорт в `CallLogCard` пропал бы при
добавлении букв (поймано до сборки). Функции Compose с общими именами
(`remember`, `produceState`, `LaunchedEffect`…) проверяются только
в файлах с `@Composable`: у `SimPreferenceRepository` свой метод
`remember(…)` — «запомнить выбор SIM».

## Что проверить на телефоне

1. Контакты: строки одной буквы — в одной карточке с разделителями,
   как группа «Сегодня» в журнале; избранные — так же; свайп строк работает.
2. Меню долгого нажатия и «Ещё» журнала: иконка заметки — серая.
3. Меню долгого нажатия: имя в шапке начинается ровно там же, где подписи
   пунктов; кружок по центру колонки иконок.
4. Карточка: внизу «Ещё» вместо «Блок»; вверху нет ⋮; «Ещё» → последним
   «Заблокировать номер» (красным) — блокирует; повторно — «Разблокировать».
5. Меню долгого нажатия: шапка (от верха шторки до кнопок) — в цвете темы,
   как круглые кнопки; в светлой, тёмной и AMOLED. Настройки → Оформление →
   «Цветная шапка меню» — выключить: шапка как фон шторки.
6. Экран вызова в тёмной теме: под системной навигацией — цвет панели,
   фото не просвечивает. Псевдозвонок — так же.
7. Журнал (в том числе у старых звонков) и контакты: у контактов без фото — буквы на цветном фоне
   («Тестовый Контакт» → «ТК», «Тест1» → «Т»); незнакомые номера — серый
   значок; пропущенный — красная подсветка.
9. Клавиатура: клавиши-«пилюли», цифра по центру, буквы под ней; поле
   номера без плашки; кнопки SIM — зелёные, без номера — светлые тональные;
   лёжа — только цифры; тёмная и AMOLED-тема. Слепой набор: попадание
   и отклик (звук, вибрация, подсветка) как раньше.
8. Настройки → Вызовы → «Мессенджеры для любого номера» — включить;
   карточка незнакомого номера → «Написать»: WhatsApp и др. (установленные);
   выбрать WhatsApp — открывается чат с этим номером.

## 17. Сбой сборки 05.10.2026 и исправление

`moreOpen`, `blockLabelRes`, `onBlockAction` (серия 9) были объявлены
в содержимом экрана, рядом с рядом кнопок, а меню «Ещё» вызывается
из верхней панели — соседнего блока выше, откуда они не видны
(«Unresolved reference», 4 ошибки от одной причины). Перенесены на уровень
функции экрана, после `haptics`. Других ошибок компилятор не сообщил.

`prebuild_check.py`, правило 43: локальная переменная (имя объявлено
в файле один раз) используется в той же функции выше объявления —
строки и комментарии не считаются, параметры функций и лямбд с тем же
именем исключены. На воспроизведённой ошибке — 1 замечание, по проекту —
0 ложных.

## 18. Прогон 06.10.2026 и буквы в журнале

| Замер | База | 1.3.5 | Изменение |
|---|---|---|---|
| Холодный запуск (без компиляции) | 239,3 мс | 231,3 мс | −3,3% (p = 0,82) |
| Тёплый запуск | 88,1 мс | 81,7 мс | −7,3% |
| Карточка | 86,6 мс | 78,2 мс | −9,7% |
| Клавиатура | 105,6 мс | 90,1 мс | −14,7% |

**Регрессия холодного запуска (+13% в 1.3.4) ушла.** Новый профиль
запуска — со строками журнала (`CallLogCard` 38 правил, свайп 47; было 0):
журнал эмулятора теперь заполняет `CallLogSeed`. Профиль 25 551 правило
(+3 310). База замеров обновлена по этому прогону (`set_baseline.py`).

**Буквы в журнале** (скриншот автора: у контактов без фото — значок).
Признак «контакт» брался из `contactId`, а он приходит из кэша системного
журнала, где ссылка на контакт часто пустая. **Стало:** `CallLogRowState
.isContact` — `contactId` или номер среди номеров книги; номер сохранили
в контакты — строка пересобирается (признак — часть отпечатка кэша строк).
Заметка в заголовке строки — буквы не из неё.

## 19. Клавиатура набора — в стиле приложения (задача автора)

«Кажется совершенно не из этого приложения» (скриншот 06.10). Три причины
и что сделано — остальное (своя поверхность клавиши, подсветка нажатия,
три канала отклика, стандартная раскладка, буквы языка главные) сохранено:

1. **Клавиши-плиты** со скруглением 20 dp и цифрой, прижатой влево, —
   такой формы и раскладки больше нигде нет. **Стало:** «пилюля»
   (`dialKey` — скругление на всю высоту, как у кнопок нижней панели);
   цифра `headlineMedium` по центру, под ней строка: буквы языка
   (`labelMedium`), рядом мельче и бледнее латиница. Строка есть и у «1»,
   «*», «#» — цифры на одной линии. Лёжа — только цифры: ряды там ниже
   52 dp, строка букв обрезалась бы.
2. **Поле номера — белая плашка**, как поле анкеты. **Стало:** без плашки,
   номер крупно прямо на панели (как имя на экране вызова); вставка
   и стирание — на месте.
3. **Кнопки вызова — синие** (цвета Button по умолчанию), а зелёный —
   только у звонка. **Стало:** `CallGreen`; без номера — тональный
   `surfaceContainerHighest` вместо грязно-серого «отключено».

Цвет клавиш — прежний `PanelColors.key()`, общий с кнопками нижней панели
и полями поиска.
