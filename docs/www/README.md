# Сайт с документами

Копия страниц ogneliss.ru/dialer и ogneliss.ru/mail. Лежит в репозитории, потому что
на эти страницы ссылается само приложение и карточка Google Play:
если они разойдутся с версией документов в приложении, узнать об этом
будет неоткуда.

## Языки

Четыре: русский, английский, немецкий, французский. Каждая страница
содержит все четыре версии блоками `<div id="lang-XX">`, переключение
скриптом на месте — отдельных файлов на язык нет.

Язык по умолчанию берётся из браузера (сравниваются первые две буквы
`navigator.language`), выбор запоминается на время сессии.

⚠️ Немецкий и французский переводы **не вычитаны носителем**. На условиях
использования, лицензионном соглашении и открытых компонентах стоит
пометка, что юридически обязательной остаётся русская версия. Снять
её можно только после вычитки.

## Что здесь лежит

| Файл | Что |
|---|---|
| `*.html` | Страницы сайта, по четыре языка в каждой |
| `style.css` | Общие стили |
| `build-pages.sh` | Сборка каталога для выкладки + проверка языков |
| `DEPLOY.md` | Как выложить на сервер |
| `nginx-ogneliss.conf`, `docker/` | Конфигурация сервера |

⚠️ **Страницы больше не генерируются из `legal/*.md`.** Из одного
русского документа нельзя собрать страницу с четырьмя языками. Правя
документ в `legal/`, те же изменения нужно внести в соответствующий
`.html` здесь — во все языковые блоки. Автоматической сверки больше нет,
и это цена многоязычности.

## Как добавить язык

1. В `site_build`-подобном порядке: добавить блок `<div id="lang-XX">`
   после английского на каждой странице.
2. Дописать код языка в массив `LANGS` и ссылку в переключателе.

Больше ничего: скрипт перебирает языки списком.

## Ogneliss Mail (`mail/`)

Страница приложения и четыре документа Mail лежат в подкаталоге `mail/`:
`index`, `privacy`, `eula`, `terms`, `licenses` — те же четыре языка
и тот же переключатель, общие `style.css`, `lang.css`, `lang.js`
и значки берутся из `/dialer/`.

В отличие от страниц Dialer, эти **не правятся вручную**: их собирает
`docs/site/build_mail_pages.py` в репозитории Mail из текстов
`docs/site/content_*.py`. Правка текста → пересборка → копия сюда.
Тот же скрипт обновляет `docs/legal/*.md` в репозитории Mail (русский
и английский), так что приложение и сайт не расходятся.

На немецкой и французской версиях всех четырёх документов Mail стоит
пометка, что обязательной остаётся русская редакция.

Ссылка на раздел: `/mail/privacy#delete` ведёт к разделу «Удаление
данных» на языке посетителя — `lang.js` переводит `#delete` в
`#delete-ru`, `#delete-en` и т. д. Этот адрес указывается в консоли
Google Play как ссылка на удаление данных.

**Перекрёстные ссылки (04.10.2026).** В подвале главной Dialer — строка
«Все приложения Огнелисс · Ogneliss Mail» на четырёх языках: с двумя
приложениями на сайте со страницы одного нельзя было попасть ни на общую
главную, ни ко второму. Страницы Mail правятся только через
`build_mail_pages.py` — ту же строку («… · Ogneliss Dialer», ссылка
`/dialer/`) стоит добавить туда, в подвал `mail/index`.
