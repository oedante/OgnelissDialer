# Ogneliss Dialer 1.2.1 — в работе

```
versionName  1.2.1
versionCode  22
Предыдущая версия: 1.2.0
```

Выпуск мелочей по первому отзыву в Google Play и отложенному —
план в `ROADMAP.md`.

## 1. Экран вызова без подложки под кнопками

Первый отзыв (Samsung Galaxy A04s, Android 14, 5 из 5) просил убрать
«большую квадратную тень вокруг кнопок». Это была светло-серая подложка
под кнопками управления: занимала треть экрана и спорила с портретом
за внимание.

Подложка убрана. Круглые кнопки группируются и сами — одинаковой
формой и ровной сеткой. Сами кружки стали заметнее: они теперь лежат
прямо на светлом фоне экрана, а не на сером.

Панель тонального набора и список участников конференции остались
на подложке: это всплывающие блоки поверх экрана, им граница нужна.

## 2. Подписи под кнопками — выключаемые

Настройки → Оформление → «Подписи под кнопками». Подписи нужны, пока
приложение незнакомо; опытному пользователю значки узнаются с первого
взгляда, а подписи занимают место. В отзыве просили про экран вызова —
сделано сразу для всего приложения:

- нижние панели журнала, контактов, заметок, напоминаний — без подписей
  строка панели ниже (60 dp вместо 72);
- круглые кнопки действий в карточке абонента;
- кнопки управления на экране вызова.

По умолчанию подписи включены.

**Доступность не страдает:** подпись прячется только с экрана.
Описание для TalkBack у каждой кнопки остаётся — там, где раньше его
заменяла видимая подпись, оно теперь появляется у значка, когда
подписи выключены.

Не касается кнопок, у которых текст — это сама кнопка («Завершить»,
«Ответить»): без текста осталась бы пустая таблетка.

## 3. Выключенный свайп теперь выключен

Проверено по вашей просьбе — и нашлись две ошибки, из-за которых
«Нет действия» в настройках свайпа работало лишь наполовину.

**Журнал: строка всё равно тянулась.** Обработчик свайпа передавался
всегда, даже для «Нет действия». Строка считает направление рабочим,
если обработчик есть, — и выключенный свайп тянулся: строка уезжала,
возвращалась, только ничего не делала. При обоих выключенных строка
продолжала перехватывать горизонтальные движения пальца. Теперь для
«Нет действия» обработчика нет: направление не тянется, а при обоих
выключенных жест отключён целиком.

**Контакты: раскрывалась пустая панель.** «Нет действия» попадало
в общую ветку создания кнопок и превращалось в кнопку панели,
которая ничего не делает. Теперь для него кнопок нет. Заодно:
если основной свайп выключен, не показываются и дополнительные
действия этого направления.

Закреплено тестом `RevealActionFactoryTest`.

**Что проверить:** Настройки → Жесты → «Свайп вправо» — «Нет действия».
В журнале и контактах строка вправо не двигается, влево работает
как раньше. Потом выключить и «Свайп влево» — строка не двигается
ни в одну сторону, а список прокручивается как обычно.

## 4. Значки в выборе действия свайпа

В списке «Свайп вправо» / «Свайп влево» у каждого действия — значок,
тот же и в том же цвете, что появляется под строкой журнала при свайпе:
зелёная трубка у «Позвонить», фирменные цвета у мессенджеров, красная
корзина у «Удалить из журнала». Список читается быстрее, а выбранное
действие потом узнаётся в журнале с первого взгляда.

У «Ничего» значка нет, но место под него оставлено — подписи стоят
ровно одна под другой.
