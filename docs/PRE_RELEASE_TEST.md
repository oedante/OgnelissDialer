# Что проверить перед публикацией

С версии rc72, когда проект впервые назвали готовым, изменилось
многое. Ниже — только то, что затронуто, и что сломается заметно.

Проверять **на release-сборке**: часть ошибок в debug не проявляется.

---

## 🔴 Критично: миграция базы данных

Версия базы поднята с 2 до 3 (таблица причин блокировки).

**Как проверить:**

1. Установите **предыдущую** версию приложения
2. Добавьте заметку к любому номеру, заблокируйте другой номер
3. Установите новую поверх, **не удаляя данные**
4. Заметка и чёрный список должны остаться

Если данные пропали — миграция не отработала, и у пользователей
при обновлении пропадёт всё. Это единственная ошибка, которую нельзя
исправить обновлением.

---

## Вызовы

| Что | Ожидание |
|---|---|
| Входящий, экран разблокирован | Только уведомление сверху, без второго экрана под ним |
| Входящий, экран заблокирован | Экран вызова во весь экран |
| Ответ из уведомления | Появляется экран разговора, уведомление уходит |
| Исходящий | Экран открывается сразу |
| Незнакомый номер с заметкой | Заметка вместо имени |
| Поворот телефона во время звонка | Портрет и имя на месте |
| Заметка во время разговора | Вводится, метки отмечаются, сохраняется после отбоя |

---

## Жесты

| Что | Ожидание |
|---|---|
| Свайп по строке | Действие срабатывает при **отрыве** пальца |
| Свайп при прокрутке списка | Не срабатывает |
| Свайп по нижней панели влево | Контакты |
| Свайп вправо в контактах | Обратно к вызовам |
| Свайп вверх с кнопки клавиатуры | Раскрывается |
| Свайп вниз по полосе номера | Скрывается |
| Набор номера пальцем по клавишам | Клавиатура **не** закрывается |

---

## Напоминания

1. Свайп «напомнить» → выбрать 5 минут
2. Дождаться уведомления
3. **Нажать на уведомление** → открывается карточка абонента
4. Поставить снова → **«Через 15 минут»** → уведомление уходит,
   приходит позже

Если разрешение на будильники не выдано, подтверждение должно
сказать «может прийти позже» и предложить «Настроить».

---

## Первый запуск

Проверяется на чистой установке: **удалить приложение**, поставить
заново.

| Что | Ожидание |
|---|---|
| Заставка | Уходит быстро, без задержки в секунду |
| Мастер разрешений | Проходится, роль диалера выдаётся |
| Подсказка о жестах | Появляется один раз при первом журнале |
| Контакты | Появляются, не мигают пустотой |
| Фотографии в журнале | Есть у тех, у кого они в книге |

---

## Настройки

| Что | Ожидание |
|---|---|
| Экран после звонка | **Выключен** по умолчанию |
| Порог автоблокировки | Список, кнопка «?» объясняет |
| Ползунок порога | Неактивен, пока автоблокировка выключена |
| SIM для свайпа | Список из трёх вариантов, не переключатель |
| Смена темы | Первым пунктом в меню (три точки) |
| Смена языка | Применяется сразу |

---

## Что проверять НЕ нужно

Эти области не менялись с прошлой проверки: T9-поиск, экспорт истории,
резервные копии, закреплённые абоненты, статистика, юридические
документы.

---

## Если найдётся ошибка

Соберите лог: **Настройки → Диагностика → Отправить журнал**.
В нём есть версия сборки и последние события — этого обычно хватает,
чтобы найти причину без воспроизведения.
