# Ogneliss Dialer 1.8.2 — без сигнала уведомления перед мелодией

```
versionName  1.8.2
versionCode  50
Предыдущая версия: 1.8.1 (49)
База данных: 8 (без изменений)
```

Откуда (03.11): пользователи 1.8.1 — «перед звонком звучит сначала
сигнал уведомления, а потом идёт звонок»; автор: «у меня тоже 1.8.1,
поднимай версию».

## Причина

С 1.8.1 при входящем на заблокированном или погасшем телефоне сразу
ставится уведомление входящего с полноэкранным показом и кнопками — без
него экран вызова поверх блокировки не поднимается (раздел 1 заметок
1.8.1). Канал этого уведомления («call_incoming») был создан ещё
в ранних версиях со звуком уведомления по умолчанию: пока уведомление
ставилось редко (только если экран вызова не открылся), этого
не замечали. С 1.8.1 оно звучало при каждом таком входящем — коротким
сигналом прямо перед мелодией, которую играет система.

Канал без звука (`call_incoming_silent`, прежний удаляется) появился
в коде 1.8.1 позже первой сборки — в архиве от 01.11 10:21. Обе сборки
назывались 1.8.1 (49), различить их по номеру нельзя. Поэтому
исправление выходит отдельным номером — 1.8.2.

## Что в 1.8.2

- **Канал входящих без звука и вибрации** — мелодию и вибрацию играет
  только система (было в коде с 01.11, теперь — в выпуске).
- **Звук канала входящих — в журнал** (`IncomingScreen.logChannelSound`):
  при первом всплывающем уведомлении входящего строка «Канал входящих:
  без звука» или предупреждение «Канал входящих со звуком: …», если звук
  включили в настройках уведомлений или его навязала прошивка. Если
  жалоба повторится — по журналу сразу видно, откуда сигнал.
- Сборка: `bundleRelease` без `keystore.properties` останавливается,
  а не подписывает бандл отладочным ключом (02.11).
- Замеры: подготовка эмулятора переживает «Process system isn't
  responding» (02.11, `docs/BUILD_TROUBLESHOOTING.md`).
- Всё из 1.8.1: экран входящего, экран вызова на любом телефоне, волны
  от имени, прошивки производителей, журнал по дням с плавающей датой
  (`docs/RELEASE_NOTES_1.8.1.md`).

«Что нового» — `store/whats_new_1.8.2.txt`, тот же текст, что у 1.8.1
(в лимит 500 знаков строка про сигнал уже не помещается).

## Что проверить на телефоне

1. **Заблокированный телефон, экран погас — позвонить:** экран
   загорается, звучит **только мелодия**, без короткого сигнала перед ней.
2. То же с включённым разблокированным экраном — только мелодия.
3. Настройки Android → Приложения → Ogneliss Dialer → Уведомления:
   категория «Входящий вызов» — без звука; второй такой категории
   (от прежних версий) нет.
4. Журнал приложения после такого звонка: строка «Канал входящих:
   без звука».
5. Остальное — список 1.8.1 (`RELEASE_NOTES_1.8.1.md`, «Что проверить
   на телефоне»).

## Команды

Архив — в чистую папку, перенося `keystore.properties` (и файл ключа,
если путь в `storeFile` относительный), `local.properties`
и `app/schemas/*.json`.

```powershell
./gradlew bundleRelease
keytool -printcert -jarfile app\build\outputs\bundle\release\app-release.aab
```

SHA1 — `BA:3B:66:1C:…`. Перед отправкой кода — `python scripts/oss_audit.py`.
