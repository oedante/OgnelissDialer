# Возможности во время вызова — что есть и чего нет

Разобрано по коду 23 сентября 2026 (`CallManager`, `InCallActivity`).

## Что уже есть

| Возможность | Где | Замечание |
|---|---|---|
| Ответить / отклонить / завершить | `CallManager.answer/reject/hangup` | |
| Выключить микрофон | плитка «Микрофон» | |
| Громкая связь | плитка «Динамик» | плюс автоматическая по датчику приближения |
| Bluetooth-гарнитура | плитка появляется, если гарнитура подключена | |
| Клавиатура во время вызова (тоновый набор) | плитка «Клавиатура» | для меню «нажмите 1» |
| Удержание | плитка «Удержать» | |
| Переключение между двумя линиями | плитка «Переключить», если линий две | |
| Конференция | плитка «Объединить», если линий две | |
| Заметка во время разговора | поле на экране вызова | |

## Что сделано в 1.1.1

Все пять пунктов ниже, кроме перевода вызова, реализованы в 1.1.1.
Проверяются только живыми вызовами — список проверок в конце.

## Чего не было

### 1. Кнопки «Добавить вызов»

Вторая линия сейчас появляется только одним путём: во время разговора
**входит** второй звонок. Позвонить **самому** третьему человеку,
не прерывая разговор, из экрана вызова нельзя — нужно выйти
в приложение и набрать номер. Технически это сработает (система
сама поставит первый вызов на удержание), но догадаться об этом нельзя.

**Как сделать:** плитка «Добавить вызов» открывает клавиатуру набора
поверх вызова; набранный номер уходит обычным путём, Android сам
ставит текущий вызов на удержание. После этого появляются
«Переключить» и «Объединить» — они уже есть.

Объём: небольшой. Проверить можно только на телефоне с настоящим
вызовом.

### 2. Проверки возможностей оператора

«Удержать» и «Объединить» показываются всегда, когда есть вызов
(или два). Но умеет ли это оператор, сообщает сама система —
флагами `CAPABILITY_HOLD`, `CAPABILITY_MERGE_CONFERENCE`
и списком `conferenceableCalls`. Мы их не читаем.

Если оператор конференцию не поддерживает, нажатие «Объединить»
ничего не делает — молча. Человек решит, что приложение сломано.

**Как сделать:** показывать плитку только при нужном флаге;
для объединения — `conference(b)`, если `b` в списке
`conferenceableCalls`, иначе `mergeConference()`, если есть
`CAPABILITY_MERGE_CONFERENCE`. Это правильный порядок по документации
Telecom: у разных сетей работает разный способ.

### 3. Управление конференцией

После объединения видна одна «конференция» без участников.
Нельзя увидеть, кто в ней, отключить одного или поговорить с кем-то
отдельно. У `Call` конференции есть `children` — участники,
у каждого `disconnect()` и `splitFromConference()`.

**Как сделать:** список участников на экране вызова, у каждого —
«отключить» и «поговорить отдельно». Объём средний.

### 4. Выбор при втором входящем

Когда во время разговора входит второй звонок, Android предлагает
«ответить и удержать» или «ответить и завершить текущий». У нас —
только «ответить», и что станет с первым вызовом, решает система.

**Как сделать:** на экране входящего при уже идущем разговоре —
две кнопки ответа вместо одной.

### 5. Перевод вызова

Android 13 и новее умеет переводить вызов на другой номер
(`Call.transfer`), если это поддерживает оператор. В России такая
услуга редкость; пункт стоит последним.

## Чего не будет

**Запись разговора.** Google Play не разрешает её приложениям, кроме
предустановленных производителем, а Android с версии 10 не даёт
доступа к звуку вызова. Это разобрано в политике конфиденциальности.

## Предлагаемый порядок

1. Проверки возможностей (раздел 2) — дешёво и убирает «кнопку,
   которая молча не работает».
2. «Добавить вызов» (раздел 1) — самое заметное из недостающего.
3. Выбор при втором входящем (раздел 4).
4. Управление конференцией (раздел 3).

Каждый пункт проверяется только настоящим вызовом, а конференция —
ещё и оператором, который её поддерживает. Вслепую делать не стоит:
ошибка во время живого разговора хуже, чем отсутствие функции.

## Как проверить на телефоне

Понадобятся второй телефон (лучше два) и оператор, у которого есть
удержание и конференция. У большинства российских операторов удержание
есть по умолчанию, конференция — иногда отдельной услугой.

1. **Добавить вызов.** Позвонить на второй телефон, во время разговора
   нажать «Добавить вызов» — откроется клавиатура. Набрать третий номер.
   Первый вызов должен уйти на удержание, экран вызова — показать новый.
2. **Переключить.** После ответа третьего — «Переключить»: разговор
   переходит на первую линию, вторая удерживается.
3. **Объединить.** «Объединить» — должна появиться панель «Конференция:
   участников 2» со списком.
4. **Участники.** У участника — «поговорить отдельно» и «отключить»,
   если их показала сеть. Если кнопок нет — сеть не разрешает, это
   не ошибка приложения.
5. **Второй входящий.** Во время разговора попросить третий телефон
   позвонить вам. Должна появиться плашка «Второй входящий вызов»
   с тремя кнопками. Проверить все три.
6. **Второй входящий из уведомления.** То же, но выйти из экрана вызова
   на главный экран телефона: «Ответить» в уведомлении должно ответить
   на звонящий вызов, а не на текущий.

Если какая-то кнопка не появилась там, где ожидалась, пришлите журнал
из «Данные и диагностика» — в нём видно, что сообщила сеть.
