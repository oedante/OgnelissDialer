## Перед тем как открыть репозиторий

Приложение 1.5.7 ведёт по кнопке «Исходный код» на
`https://github.com/oedante/OgnelissDialer`. **Репозиторий должен стать
открытым до того, как 1.5.7 дойдёт до пользователей**, иначе кнопка
откроет страницу 404.

### 1. История — начать заново

Историю репозитория я не видел: из этой работы к нему нет доступа.
В старых коммитах может лежать то, что уже убрано из рабочей папки:
настоящие номера в комментариях и тестах (заменены только в 1.5.7),
`keystore.properties`, журналы диагностики, снимки экрана.

Надёжнее всего — открыть код **с новой историей**, а старый
репозиторий оставить закрытым архивом:

1. На GitHub: старый репозиторий → Settings → переименовать,
   например в `OgnelissDialer-archive`; он остаётся закрытым.
2. Создать новый открытый репозиторий `OgnelissDialer` — пустой,
   без README и лицензии (они уже есть в проекте).
3. Из папки проекта последней версии (1.6.2) — не из старого клона:

```powershell
python scripts/oss_audit.py
git init -b main
git add -A
git status          # глазами: нет ли keystore.properties, *.jks, local.properties
git commit -m "Ogneliss Dialer 1.6.2 — открытый код (Apache 2.0)"
git remote add origin https://github.com/oedante/OgnelissDialer.git
git push -u origin main
git tag v1.6.2
git push origin v1.6.2
```

Почему не «переписать историю и отправить с --force»: GitHub ещё
какое-то время отдаёт старые коммиты по прямой ссылке на их хеш, даже
когда ни одна ветка на них не указывает. Новый репозиторий этого
вопроса не оставляет.

### 2. Проверка перед первой отправкой

`python scripts/oss_audit.py` — на 22.10: ключей и паролей нет, чужих
номеров нет. Осталось просмотреть глазами то, что скрипт перечисляет:

- адреса почты: пример адреса WhatsApp в комментарии
  (`ContactMessengers.kt`) и шаблон `user@ogneliss.ru` в `docs/www/DEPLOY.md` —
  вымышленные, можно оставить;
- картинки в `docs/` и `store/` — макеты с вымышленными именами
  и снимки, которые и так опубликованы в Google Play;
- `docs/baseline/*.json` — замеры скорости: модель телефона и версия
  прошивки, без серийного номера.

Ключ подписи, `keystore.properties` и `local.properties` в репозиторий
не попадают (`.gitignore`). Журналы (`*.log`) и дампы памяти (`*.hprof`)
с 1.5.7 — тоже.

| Реклама, покупки в приложении | Не менять: нет |

**Если чужая версия появится в Google Play под похожим названием или
со значком Ogneliss** — это нарушение `TRADEMARKS.md` и раздела 6
лицензии; жалоба подаётся через форму Google Play о нарушении прав
на товарный знак. Версия под своим названием и со своим значком
с сохранённым NOTICE — разрешена лицензией.
