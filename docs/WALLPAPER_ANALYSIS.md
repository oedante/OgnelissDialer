# Обои рабочего стола как фон — разбор (01.10.2026)

Функция была в 1.3.0 (28), не прошла внутренний тест и закрыта.
Код удалён; последняя версия с ним — архив `OgnelissDialer_1_3_0_wip.zip`.

## Причины симптомов

| Симптом | Причина | Механизм |
|---|---|---|
| Шлейфы, «призраки» | `colorScheme.background = Color.Transparent` | Прозрачными стали все 22 `Scaffold`: при переходах и шторках старый и новый экран видны одновременно |
| Мигание при включении и смене размытия | `window.setFormat(TRANSLUCENT)` после `setContent`, в `LaunchedEffect` с ключом размытия | Смена формата пересоздаёт поверхность окна — пустой кадр |
| Мигание панелей | `SideEffect` без ключей в теме | На каждой перерисовке темы — `clearFlags` и `setBackgroundDrawable`: перераскладка окна |
| Лаги прокрутки и анимаций | `setBackgroundBlurRadius` на весь экран | Размытие пересчитывается каждый кадр, окно сводится на GPU |
| Нагрузка в фоне | `FLAG_SHOW_WALLPAPER` | Живые обои продолжают рисоваться под приложением |

## Решение

Не возвращать в таком виде. Похожее ощущение даёт палитра из обоев
(`dynamicColor`, Android 12+), она уже есть в теме. Любая будущая
попытка — только за выключенным по умолчанию флагом, отдельной
реализацией, без прозрачных `Scaffold` и без размытия во весь экран,
с замерами до и после.
