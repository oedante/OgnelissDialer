# Ogneliss Dialer 1.3.4 — в работе (внутренний тест)

```
versionName  1.3.4
versionCode  32
Предыдущая версия: 1.3.3
```

Фаза 4 плана аудита — «Архитектура и интерфейс». Публичного выпуска
не будет: сборки — во внутренний тест, в рабочую версию — 1.4.0.
Поведение для пользователя не меняется, если не сказано иное.

## 1. DialerViewModel: выгрузки и резервные копии — в ExportController

**Было:** `DialerViewModel` — 3085 строк, 26 зависимостей; выгрузка
истории абонента, CSV журнала, резервные копии, запись файлов и текст
журнала приложения жили в ней.

**Стало:** `backup/ExportController.kt` по образцу
`ContactActionsController`: `@Singleton`, без состояния экрана — заметки,
отметки и контакты ViewModel передаёт параметрами. ViewModel только
делегирует (одна строка на функцию), экраны не менялись. Константы
`EXPORT_LIMIT` и `CSV_EXPORT_LIMIT` переехали вместе с кодом.
`BackupManager` больше не зависимость ViewModel. 3085 → 3039 строк.

**Рассмотрено и не делается:** быстрый набор уже вынесен
в `SpeedDialStore` — ViewModel лишь передаёт вызовы.

## 2. DialerViewModel: закреплённые — в PinnedController

**Было:** закрепление, открепление, перестановка, перевод старых записей
на контакты и сборка строк экрана «Закреплённые» — в ViewModel; перевод
и строки без телефона не проверялись.

**Стало:** `data/PinnedController.kt`. Запись в настройки — методы

(экран «Закреплённые» обновлён). ViewModel ищет ключ контакта, держит
список и обновляет журнал после записи. 3039 → 3010 строк.

**Тесты:** `PinnedControllerTest` — 5: перевод номера на контакт; «менять
нечего — в настройки не пишем» (защита от цикла подписки); строка экрана
с последним звонком с другого номера; пустой журнал; удалённый контакт.

## 3. «Поделитьс / я» в карточке лёжа — исправлено по-настоящему

Скриншот автора (1.3.3): в карточке лёжа подпись снова рвалась посреди
слова, хотя `FitText` стоял с 1.3.2.

**Причина:** `FitText` мерил слово стилем `labelSmall`, а `Text` рисует
`LocalTextStyle.current.merge(style)`. У «Поделиться» лёжа ширина впритык:
по замеру влезало — масштаб не включался, — а при отрисовке не хватало
пары пикселей. Буквы на скриншоте того же размера, что у соседей, — это
и выдало, что уменьшения не было.

**Стало:** замер тем же смешанным стилем, что и отрисовка, и запас 4%
(округление при отрисовке не решает, переносить ли последнюю букву).
Касается всех мест с `FitText`: кнопки карточки и меню, SIM-кнопки.

## 4. Иконки — Material Symbols Rounded (выбор автора)

**Было:** `material-icons-extended` — Google заморозил библиотеку
на 1.7.8; стиль — заливка образца 2018 года.

**Стало:** `ui/theme/OgnelissIcons.kt` — 104 иконки Material Symbols
Rounded, только используемые, без зависимостей: пути SVG из
github.com/google/material-design-icons (Apache 2.0), собранные
в `ImageVector` публичным API Compose; разбор пути — при первом показе
(`by lazy`). 276 использований в 40 файлах: `Icons.Default.X` →
`OgnelissIcons.X` (имена прежние). Зависимость `material-icons-extended`
убрана.

**Стиль:** контур (FILL 0, вес 400) — вид Android 15–16. Залиты только
иконки, где заливка несёт смысл: звонок, отбой, «закреплено»,
«избранное» (пара «залитая звезда — контур» сохранена). Направленные
(стрелки, «отправить», типы вызовов) отражаются для языков справа налево.

**Где имя в Symbols другое:** `AddIcCall` → add_call, `Textsms` → sms,
`Clear` → close, `Email` → mail, `FileDownload`/`FileUpload` →
download/upload, `Message` → chat, `Restore` → settings_backup_restore
(кнопка сброса на экране настройки свайпа).

**Новая иконка или смена стиля:** строка в `scripts/icons_manifest.json`
и `python scripts/build_icons.py [--style rounded|outlined|sharp]`.

**Лицензии:** Material Symbols добавлены в приложение (ru, en) и на сайт
(4 языка).

**Не тронуто:** значки уведомлений и ярлыков — векторные XML в `res/drawable`;
их перевод на Symbols — вместе с дизайн-системой.

## 5. Значки уведомлений — свой у каждого типа

**Было:** у всех уведомлений одна трубка: пропущенный, напоминание,
заблокированный вызов, предложение перезвонить — в строке состояния
не различить.

**Стало:** значки из Material Symbols Rounded (`res/drawable/ic_stat_*`):
пропущенный — `call_missed`, напоминание — будильник, заблокированный —
знак запрета, «перезвонить?» — обратный вызов. Уведомление о звонке
и ярлыки — прежний `ic_call`, путь обновлён до Symbols.

## 6. Цвета свайпа — один «звонок», один «написать»

**Было:** подсказка прямого действия (свайп с одним действием) рисовала
фон полупрозрачным — нарастающая яркость сообщала, засчитается ли жест.
Полупрозрачный зелёный поверх карточки — другой, бледный зелёный: в одном
журнале выходило три оттенка «звонка», синий «Написать» бледнее основного
(аудит, «Дизайн-система»).

**Стало:** фон — сплошной цвет действия (тот же `CallGreen`/`MessageBlue`,
что у кнопок и значков). Обратная связь сохранена — в значке: проявляется
(45% → 100%) и подрастает (75% → 100%) по мере сдвига.

## 7. «Отправлять вызовы на голосовую почту» — ошибка и состояние

**Было:** в меню «Ещё» карточки — обычная строка без состояния, и нажатие
**всегда включало** отправку на голосовую почту (`setSilentContact(id, true)`):
включив, выключить из приложения было нельзя.

**Стало:** строка с переключателем (`SheetSwitchRow`): видно, включено ли
(значение читается из книги — `ContactWriter.isSendToVoicemail`); нажатие
переключает в обе стороны; шторка не закрывается — результат виден сразу.
Для TalkBack — один элемент с ролью «переключатель».

## 11. Экраны: вспомогательные части — в отдельные файлы

`SubscriberScreen.kt` 2865 → 2329 строк (+ `SubscriberParts.kt`),
`MainDialerScreen.kt` 2490 → 2099 (+ `MainDialerParts.kt`): строки
истории и журнала, меню, разделы, шторки. Код не менялся, видимость
`private` → `internal`. Сверено с 1.3.3: потерялись только импорты старых
иконок.

**Сбой сборки 05.10.2026 и исправление.** `LOAD_MORE_THRESHOLD`
был объявлен `private const val`: при переносе `private` менялся на
`internal` шаблоном, который не учитывал модификатор `const`, — константа
осталась закрытой в `MainDialerParts.kt`, а `MainDialerScreen.kt` ею
пользуется. Исправлено (`internal`); `import_check.py` теперь учитывает
все модификаторы между `private` и объявлением (`const`, `suspend`,
`inline`, `operator`…) — проверено на этой же ошибке: одно замечание
до исправления, ноль после. Других ошибок компилятор не сообщил — он
перечисляет все ошибки модуля сразу, значит остальное новое в 1.3.4
компилируется.

**Сборка 05.10.2026, второй прогон.** Приложение собралось. Упали
модульные тесты: в именах тестов `PinnedControllerTest` в обратных
кавычках стояло двоеточие («перевод: номер из книги…»), а на JVM в имени
метода запрещены `. ; [ ] / < > : \`. Заменено на тире (8 имён).
`prebuild_check.py`, правило 41, ловит такие имена до компиляции —
проверено на этой же ошибке. Заодно убран лишний `?.` в `CallScreenParts`:
Kotlin 2 сам выводит, что `controller` не null, раз не null полученный
через него `before` (предупреждение компилятора).

**Отложено до компиляции:** сами функции экранов — по ~2000 строк каждая;
резать их — выносить куски с общим локальным состоянием, без компилятора
слишком рискованно. То же для крупных функций ViewModel: действия свайпа
(~400 строк), загрузка журнала (~480), поиск (~130).

## 12. Удаление контакта — с подтверждением и закреплёнными (задача автора)

**Было:** удалить контакт из приложения было нельзя. В карточке диалог
подтверждения был написан, но вызвать его было нечем; `deleteContacts`
не вызывался нигде. И если бы удаление сработало, закрепление осталось бы:
в журнале висел бы закреплённый «по запасному номеру» без имени и фото.

**Стало:**
- пункт «Удалить контакт» — в меню «Ещё» карточки (красный, последним
  в группе контакта) и в меню долгого нажатия у записей контактов
  (в нижнем блоке необратимых действий, под «Удалить из журнала»);
- общий диалог `DeleteContactDialog`: необратимость и «из всех аккаунтов»;
  если контакт закреплён — строка «он будет убран и из закреплённых»;
- `DialerViewModel.deleteContact`: сначала удаление из книги; только если
  оно прошло — снимаются **все** закрепления контакта (по ключу и по каждому
  номеру: закрепления до 1.3.2 могли быть по номеру); сообщение «Контакт
  удалён» или «Не удалось удалить контакт». `deleteContacts` — тем же путём.

Строки — 4 языка. Тесты: 3 новых в `PinnedControllerTest` (по ключу,
старые по номеру, чужие не трогаются).

## 16. Экран вызова — фото на весь экран, управление в панели

**Было:** круглое фото 132 dp на сплошном фоне, кнопки внизу экрана.

**Стало (портретная раскладка, у контакта есть фото):**

  тёмные потерялись бы), потом — как было;
- управление — в нижней панели со скруглением 28 dp на всю ширину, как
  нижняя панель журнала; панель есть и без фото.

Лёжа и в позе «ноутбук» — прежний вид: по высоте места мало.

с фото и без; светлая и тёмная тема; удержание, второй вызов, клавиатура
во время разговора (поле набора в панели); поворот; псевдозвонок
со «Случайным контактом» с фото.

## 17. Холодный запуск: регрессия +15% и две причины

**Замер 05.10.2026** (холодный запуск теперь первым, на остывшем
телефоне): 276,1 мс против базы 239,3 мс, p = 0,01. Повторы не растут
(229–318) — это не нагрев. Тёплый запуск, карточка, клавиатура — без
изменений; память +0,9%. Замер шёл на новой сборке: перед ним Gradle
собрал всё заново (85 из 85 задач).

После базы в путь запуска попали две правки 1.3.4:

1. **Иконки** собирались из строк SVG (`addPathNodes("M798-120q…")`) —
   строка разбиралась при первом показе. На первом кадре журнала ~10 иконок,
   а `startupNoCompilation` меряет режим без компиляции, где разбор чисел
   из строк медленный. **Стало:** пути — вызовами `PathBuilder`
   (`moveTo`/`lineTo`/`quadTo`…), как в библиотеке Google `material-icons`;
   5534 команды на 104 иконки, переведены в абсолютные координаты
   библиотекой `svgpathtools` (не самодельным разбором). Генератор
   `build_icons.py` пишет так же (нужен `pip install svgpathtools`).
2. **`FitText` в кнопках нижней панели** — ставился ради боковой колонки,
   а работал во всех пяти кнопках журнала: замер текста и вложенная
   разметка на первом кадре. **Стало:** `LabeledIconButton(fitLabel = …)`,
   по умолчанию обычный `Text`; `FitText` — только в боковой колонке лёжа.

Подтвердится следующим `phone_check.ps1`: холодный запуск должен вернуться
к ~240 мс. Если нет — разбирать трассы Perfetto (лежат рядом с замерами).

## 20. Карточка контакта — переработка (задача автора)

Разбор по `docs/DESIGN_SYSTEM.md`: карточку почти не трогали, пока
остальной интерфейс менялся. Четыре расхождения — исправлены:

1. **Быстрые действия — внизу.** Было: ряд «Позвонить · Написать ·
   Поделиться · Напомнить · Блок» в шапке под фото — уезжал вверх при
   прокрутке, до «Позвонить» на большом телефоне не дотянуться одной рукой
   (принцип «частое — в нижней трети»). Стало: стоя — неподвижная нижняя
   панель (`bottomPanel`, `surfaceContainer`), как в журнале и на экране
   вызова; список прокручивается над ней. Шапка отдельной колонкой
   (широкий экран) — ряд остаётся в ней. Сами действия не менялись: ряд
   перенесён целиком в `quickActions`.
2. **Отметка «Спам / Мошенники» у контактов из книги** — блок скрыт:
   своих контактов спамом не отмечают. Виден у незнакомых номеров;
   у контакта — если отметка уже стоит (видно и можно снять) или после
   «Ещё» → «Отметить как спам».
3. **Пустая заметка — одна строка**: значок, «Добавить заметку»,
   карандаш, без заголовка панели. Заметка есть — прежняя панель.
4. **История вызовов — как журнал**: группы «Сегодня», «Вчера», «На этой
   неделе» (тот же `LetterHeader`, деление — общий `CallLogDateGroup.of`);
   строка — время и длительность, тип вызова значком (TalkBack читает его
   словом), пропущенный — красным; в «Сегодня» и «Вчера» только время;
   номер второй строкой — только у абонента с несколькими номерами.
   Было три строки на вызов: «Исходящий / Вчера, 14:35 / номер».

**Проверено и оставлено:** отступов вне шкалы — один (2 dp, осознанно),
зашитых цветов нет; имя без фото — `titleLarge` (в коде записано: как
заголовки экранов, иначе карточка читалась отдельным приложением), поверх
фото — `headlineMedium` (крупный текст на снимке, как на экране вызова).

**Сбой сборки 05.10.2026 и исправление.** `icon = if (noteEmpty) null else
{ Icon(…) }` — скобки после `else` в Kotlin это блок, а не лямбда: он сразу
вызывает `Icon` и возвращает `Unit`, а слот ждёт функцию. Синтаксически
верно — проверка синтаксиса не видит. Исправлено на `else { { Icon(…) } }`.
`prebuild_check.py`, правило 42, ловит такие слоты Compose (`icon`,
`leadingIcon`, `supportingContent`…) до сборки — проверено на этой же
ошибке. Других ошибок компилятор не сообщил: остальное в пачке
компилируется.

## Что проверить на телефоне

1. Карточка → «Выгрузить историю вызовов» — файл с историей и заметкой.
2. Настройки → Данные и диагностика: экспорт журнала в CSV, резервная
   копия — экспорт и импорт, сохранение журнала приложения.
3. Карточка лёжа: «Поделиться» в одну строку (чуть мельче соседей);
   SIM-кнопки лёжа — имена целиком.
4. Иконки — все экраны в светлой и тёмной теме: журнал, клавиатура,
   карточка, меню записи, экран вызова, настройки, фильтры; нет пустых
   мест и «квадратиков»; звонок и отбой — залитые, звезда «избранного»
   заливается при нажатии.
5. Уведомления: пропущенный, напоминание, заблокированный, «перезвонить?» —
   у каждого свой значок в строке состояния.
6. Свайп с одним действием: фон сразу сплошной зелёный/синий, значок
   проявляется и растёт; цвет совпадает с кнопкой «Позвонить» в карточке.
7. Карточка контакта → «Ещё» → «Отправлять вызовы на голосовую почту»:
   переключатель показывает состояние, включается и выключается.
8. Клавиатура лёжа: у кнопок колонки справа — подписи.
9. «Ещё» → «Псевдозвонок»: «Кто звонит» — с рамкой и стрелкой, текст
   в плитках по центру.
10. Журнал с двумя SIM: «▯1», «▯2» у строк.
11. Удаление контакта: меню долгого нажатия у контакта → «Удалить
    контакт» → подтверждение; у закреплённого — строка про закреплённые;
    после удаления он пропал и из книги, и из закреплённых, сообщение
    «Контакт удалён». То же из карточки → «Ещё». Проверять на тестовом
    контакте — удаление необратимо.
12. Экран вызова: звонок контакту с фото — фото на весь экран, имя
    светлым, значки строки состояния светлые, кнопки в нижней панели;
    без фото — прежний вид с панелью; лёжа — прежний вид. Псевдозвонок —
    так же.
13. Внешний вид всех экранов не должен измениться от замены отступов
    на токены — сравнить со скриншотами 1.3.3.
14. Карточка контакта с фото: имя крупное, белое, читается в светлой
    и тёмной теме; нижние углы фото скруглены. Экран вызова: «Соединение…»
    — тёмная плашка, белый текст.
15. Карточка стоя: кнопки «Позвонить…Блок» — в нижней панели, не уезжают
    при прокрутке; лёжа на широком экране — в колонке слева. У контакта
    из книги нет блока «Отметка»; «Ещё» → «Отметить как спам» — блок
    появляется. Пустая заметка — одна строка. История — группами по датам,
    строки в одну линию; пропущенный — красным; у абонента с двумя
    номерами — номер второй строкой.
16. Закрепить контакт, переставить вверх/вниз на экране «Закреплённые»,
   открепить из меню записи и из списка; после установки поверх —
   закреплённые на месте.
