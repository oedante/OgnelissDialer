# Ogneliss Dialer на прошивках производителей

Проверка 01.11.2026 (1.8.1), задача автора: «проверим реализацию хотя бы
для основных прошивок Android (Huawei, OPPO, Lenovo, Samsung, Xiaomi,
OnePlus и что ещё сам посчитаешь нужным)». Повод — отзыв тестировщика
с realme на Android 10: «при звонке не загорается экран».

Проверено по коду и по описаниям прошивок, без телефонов. Что нужно
посмотреть на живом телефоне, собрано в конце.

## Что важно диалеру и где ломается

| Что | Чистый Android | Где производитель мешает |
|---|---|---|
| Стать «Телефоном» по умолчанию (`ROLE_DIALER`) | системное окно | окно не появляется, если выбор уже дважды отклоняли; оболочка может заменить окно своим |
| Открыть экран вызова из фона | можно: служба вызовов, к которой подключилась система, — исключение из запрета | Xiaomi, vivo, OPPO/realme/OnePlus — свои запреты, по умолчанию включены |
| Показать экран вызова поверх блокировки | `setShowWhenLocked` | Xiaomi («Экран блокировки»), vivo («Показ на экране блокировки») |
| Полноэкранное уведомление входящего | Android 14+: можно отозвать | у всех одинаково |
| Пропущенные и напоминания без открытия приложения | энергосбережение | Xiaomi, Huawei/Honor, OPPO/realme/OnePlus, vivo, Samsung, Tecno/Infinix |

## По производителям

| Производитель, оболочка | Что мешает | Что делает приложение (1.8.1) | Что сделать человеку |
|---|---|---|---|
| **Xiaomi, Redmi, POCO** (MIUI, HyperOS) | «Другие разрешения»: «Экран блокировки», «Всплывающие окна, когда приложение работает в фоне» — для сторонних выключены. Автозапуск. Плавающие уведомления по каналам | **Проверяет оба разрешения** (коды AppOps прошивки 10020 и 10021 — так проверяет экран звонка Telegram); шаг мастера «Экран входящего вызова» и строка в «Разрешениях» с галочкой; кнопка открывает «Другие разрешения» приложения. Автозапуск — экран «Автозапуск» | Разрешить оба, автозапуск, «Без ограничений» в батарее |
| **vivo, iQOO** (Funtouch OS, OriginOS) | «Всплывающие окна в фоне», «Показ на экране блокировки», автозапуск | Шаг мастера и строка в «Разрешениях» — подсказкой (состояние прошивка не отдаёт); кнопка открывает разрешения приложения в i Manager | Разрешить оба, автозапуск |
| **OPPO, realme, OnePlus** (ColorOS, realme UI, OxygenOS 12+) | «Плавающие окна» (поверх других приложений), автозапуск, «Работа в фоне» | **Проверяет «Поверх других приложений»**; шаг мастера и строка с галочкой; автозапуск — экраны ColorOS (новые и старые имена), у OnePlus — и ColorOS | Разрешить плавающие окна, автозапуск, работу в фоне |
| **Huawei** (EMUI, HarmonyOS 2–4) | «Запуск приложений»: автозапуск, косвенный запуск, работа в фоне | Шаг «Автозапуск» — экран «Запуск приложений» | «Управлять вручную» — все три. HarmonyOS NEXT (5) — не Android, приложение там не работает |
| **Honor** (MagicOS, после отделения) | То же, но пакет `com.hihonor.systemmanager` | Автозапуск: сначала экран Honor, потом Huawei | Как у Huawei |
| **Samsung** (One UI) | «Спящие приложения», «Ограничения в фоне» | Шаг «Автозапуск» открывает экран батареи (раньше — свойства приложения); шаг «Работа в фоне» | «Работа в фоне» — «Без ограничений». Экран вызова Samsung не ограничивает |
| **Tecno, Infinix, itel** (HiOS, XOS) | «Phone Master»: автозапуск, усыпление | **Новое:** шаг «Автозапуск» и экран автозапуска Phone Master | Разрешить автозапуск, убрать из «очистки» |
| **Motorola, Lenovo** (My UX, ZUI) | почти чистый Android | Особых шагов нет; «Работа в фоне» — как у всех | — |
| **Google Pixel, Nothing, Sony** | чистый Android | — | — |
| **Все на Android 14+** | «Полноэкранные уведомления» можно отозвать: тогда входящий на блокировке — плашка на 60 с, без экрана вызова | **Проверяет** (`canUseFullScreenIntent`); выключено — шаг и строка появляются на любом телефоне, кнопка ведёт на этот экран; в логе предупреждение при каждом входящем | Включить |

Google Play оставляет полноэкранные уведомления включёнными по умолчанию
только приложениям для звонков и будильников; в Play Console это
декларация «App content → Full-screen intent». Ogneliss Dialer —
приложение для звонков; если декларация не заполнена, у новых установок
разрешение будет выключено, и шаг мастера это покажет.

## Что сделано в 1.8.1

- **Экран входящего** (`util/IncomingCallAccess.kt`): состояние
  (выдано / не выдано / не проверить / не нужно), экран прошивки,
  полоса «Телефон не дал показать экран вызова» — **только после входящего,
  у которого экран вызова действительно не появился** (`IncomingScreen.checkShown`):
  подсказку видит тот, у кого не работает, а не каждый.
- **Где найти:** шаг мастера «Экран входящего вызова»; строка в «Настройки →
  Разрешения»; пункт «Настройки → Настройки Android → Экран входящего
  вызова»; вопрос «Экран вызова не появляется…» в «Вопросах и ответах»
  (и на сайте).
- **Канал входящих без звука.** Мелодию играет система; у прежнего канала
  был звук уведомления по умолчанию, и с 1.8.1 (уведомление входящего —
  при каждом звонке на блокировке) он звякал бы поверх мелодии. Канал
  новый (`call_incoming_silent`), прежний удаляется.
- **Автозапуск:** Honor (`com.hihonor.systemmanager`), Tecno/Infinix/itel
  (Phone Master), Samsung (экран батареи), новые имена экранов ColorOS
  и vivo; производитель Transsion распознаётся по полному названию
  («TECNO MOBILE LIMITED»).
- **Окно выбора «Телефона» не открылось.** Раньше приложение вело на экран
  «Изменение системных настроек» и советовало там что-то разрешить:
  с ролью «Телефон» это не связано, а приложение этого разрешения
  и не объявляет — переключатель там серый. Теперь — сразу «Приложения
  по умолчанию» и честное объяснение причин.

## 2.0.0: сообщения, роли и установка из файла

Сквозная проверка вызовов, SMS, разрешений, экрана блокировки, контактов
и работы в фоне (05.11.2026).

**Шаги, которые человек не обязан угадывать сам:**

- **Установка из файла APK** (выпуск с GitHub): Android 15+ ограничивает
  такие приложения. Под ограничение попадают роли «Телефон» и «SMS»
  и разрешения SMS. Вместо окна выбора система пишет «Ограниченная
  настройка».
  - Откуда установлено приложение, говорит
    `InstallSourceInfo.packageSource` (LOCAL_FILE / DOWNLOADED_FILE).
  - После отказа в любом окне роли (мастер, «Разрешения», полоса
    в журнале, «Сообщения» в настройках, переписка) открывается
    подсказка с кнопкой «Открыть „О приложении“». Там: ⋮ → «Разрешить
    ограниченные настройки».
  - Отказ в SEND_SMS при такой установке разбирается так же.
  - Код: `util/RoleAccess.kt`, `RoleHelpDialog`,
    `MainActivity.onActivityResult`.
  - Из Google Play (и других магазинов, ставящих сеансом
    PackageInstaller) ограничения нет.
- **Окно роли не показалось** (выбор уже дважды отклоняли или оболочка
  подменила окно): ответ быстрее 0,8 с. Тогда открывается подсказка
  и «Приложения по умолчанию».
- **Роль SMS выдана** — приложение сразу спрашивает уведомления
  (Android 13+). Без них входящие SMS приходили бы молча.
- **Автозапуск** (Xiaomi, Huawei/Honor, OPPO/realme/OnePlus, vivo,
  Samsung, Tecno/Infinix): без него закрытое приложение может не
  получить SMS, а состояние прошивки не отдают. Поэтому в переписке
  один раз показывается полоса «разрешите автозапуск» с кнопкой на экран
  прошивки.
- **Две SIM, «Спрашивать каждый раз»**: карты SMS по умолчанию нет.
  Часть прошивок без неё не отправляет SMS вовсе. Поэтому берётся карта
  последнего сообщения переписки, иначе карта из настроек, иначе первая
  активная. Выбранная карта видна в строке ввода
  (`SmsSender.resolveSubId`).
- **Экран блокировки**:
  - уведомление SMS — `VISIBILITY_PRIVATE` с открытой версией «Новое
    сообщение» (без имени, текста и кода), если человек скрыл содержимое;
  - «Копировать код» с заблокированного экрана — только после
    разблокировки (`setAuthenticationRequired`, Android 12+).

**Без сервисов Google** (LineageOS, /e/OS, GrapheneOS, Huawei без GMS):
- приложение не зависит от Google Play Services, `INTERNET` нет;
- вызовы, SMS/MMS (SmsManager), контакты, справочник операторов —
  платформенные API и данные внутри приложения;
- контакт сохраняется в «Телефон» — запись прошивки (Samsung, Xiaomi)
  или null-аккаунт, если Google-аккаунта нет
  (`ContactEditRepository.accounts`);
- автоподстановку кода в чужие поля без Google делает клавиатура
  (если умеет); копирование кода работает везде.

**Чего приложение не может сделать за человека** (Android не даёт):
- включить автозапуск и «Без ограничений» в батарее;
- снять «Ограниченные настройки»;
- выдать роль без системного окна;
- включить RCS (он закрыт для сторонних приложений SMS).

Везде, где нужен шаг человека, есть кнопка прямо на нужный экран.

**Проверить на телефонах (2.0.0):**
1. **APK из GitHub, Android 15+:**
   - «Назначить» в мастере → «Ограниченная настройка» → подсказка;
   - «О приложении» → ⋮ → «Разрешить» → снова «Назначить» → роль выдана;
   - то же для «SMS по умолчанию».
2. **Xiaomi/HyperOS:**
   - стать SMS по умолчанию → запрос уведомлений → полоса автозапуска
     в переписке;
   - смахнуть приложение из недавних, прислать SMS → уведомление;
   - проверить «Служебные SMS» (коды банков) — приходят ли
     в переписку. Если прошивка их прячет, записать сюда.
3. **Две SIM, «Спрашивать каждый раз»:** в переписке выбрана карта,
   SMS уходит.
4. **Блокировка с «Скрыть содержимое»:** в шторке «Новое сообщение»;
   «Копировать код» просит разблокировку.
5. **Без Google (LineageOS / /e/OS):**
   - назначить телефон и SMS;
   - позвонить, отправить SMS и MMS;
   - создать контакт → он в «Телефоне».

## Чего проверить нельзя

- vivo — состояние «всплывающих окон» прошивка не отдаёт: шаг остаётся
  подсказкой, без галочки.
- Автозапуск — ни у кого: тоже подсказка.
- Имена экранов прошивок меняются от версии к версии; каждый вариант
  проверяется перед запуском (`resolveActivity`), не нашлось — открываются
  свойства приложения.

## На телефонах (когда будут под рукой)

1. **Xiaomi/Redmi/POCO:** мастер — шаг «Экран входящего вызова» без
   галочки; кнопка открывает «Другие разрешения»; разрешить «Экран
   блокировки» и «Всплывающие окна в фоне» → вернуться — галочка.
   Запретить снова, позвонить на заблокированный телефон — после звонка
   в приложении полоса «Телефон не дал показать экран вызова».
2. **realme/OPPO/OnePlus:** то же с «Поверх других приложений».
3. **vivo:** кнопка открывает разрешения приложения в i Manager.
4. **Honor, Tecno/Infinix:** «Автозапуск» открывает экран прошивки,
   а не свойства приложения.
5. **Android 14+:** выключить «Полноэкранные уведомления» у приложения —
   шаг появился и на Samsung/Pixel; позвонить на заблокированный — плашка
   с кнопками, в логе «Полноэкранные уведомления запрещены».
6. **Любой:** входящий на заблокированном телефоне — нет звяканья
   уведомления поверх мелодии.
