# Ogneliss Dialer 1.3.1

Выпуск без обоев рабочего стола. Подтверждение необратимых действий,
закреплённые при пустом журнале, имя на обложке карточки.

```
versionName  1.3.1
versionCode  29
Предыдущая версия: 1.2.6
```

**Почему 1.3.1, а не 1.3.0.** Сборка 1.3.0 (28) ушла во внутреннее
тестирование с обоями как фоном и не прошла его: мигание панелей,
шлейфы при переходах, задержки. Номер 28 в консоли занят, поэтому
та же база без обоев выходит как 1.3.1 (29). Локальная сборка 29
с обоями была только на телефоне автора. Разбор причин —
`docs/WALLPAPER_ANALYSIS.md`.

Миграций базы нет. Новых разрешений и зависимостей нет.

## 1. Необратимые действия — только с подтверждением

Найдено пользователем 30.09.2026: «Очистить журнал» стирал весь журнал
сразу, без вопроса. Окно подтверждения потерялось в 1.2.1, когда меню
«Ещё» стало шторкой. Ошибка есть в 1.2.1–1.2.6.

**Исправлено:**
- **«Очистить журнал»** — окно подтверждения: что удаляется (журнал
  и здесь, и в системном журнале телефона), что остаётся (заметки,
  закреплённые, напоминания, списки блокировки), отменить нельзя.
- **Удаление свайпом** («Удалить из журнала» как действие свайпа) — тоже
  с подтверждением: свайп легко сделать случайно, запись удаляется
  из системного журнала навсегда. Окно — в `RootScreen` (`deleteRequest`).
- **Закреплённые карточки при пустом журнале** — показываются. Раньше
  раздел закреплённых выводился только при непустом журнале: после
  очистки закреплённые пропадали до первого нового звонка.

**Проверены остальные необратимые действия:**

| Действие | Подтверждение |
|---|---|
| Очистить журнал | ✅ добавлено в 1.3.1 |
| Удаление свайпом | ✅ добавлено в 1.3.1 |
| Удаление выбранных записей (режим выбора) | ✅ было |
| Удаление контакта (карточка) | ✅ было |
| Сброс настроек | ✅ было |
| Блокировка всех незнакомых | ✅ было |
| «Удалить из журнала» в меню записи | не нужно: явный красный пункт после долгого нажатия |
| Снятие блокировки, очистка цифры быстрого набора, отмена напоминания | не нужно: восстанавливается за одно действие |
| Восстановление из резервной копии | не нужно: дополняет данные, ничего не стирает |

## 2. Имя на обложке карточки — выше

Имя лежало на самой границе обложки (4 dp от края) — теперь 16 dp.

## Что проверить на телефоне

1. **«Очистить журнал»** — спрашивает подтверждение; «Отмена» ничего
   не удаляет. После очистки закреплённые карточки на месте.
2. **Удаление свайпом** — спрашивает подтверждение.
3. **Карточка с фото** — имя не на самой границе обложки.
