# Чек-лист соответствия правилам Google Play
**Ogneliss Dialer** · обновлено 06.08.2026

Проверять перед каждой отправкой на ревью. Отмеченные ❗ пункты — те,
из-за которых чаще всего отклоняют именно диалеры.

## 1. Разрешения повышенного риска ❗

| Требование | Статус |
|---|---|
| `CALL_LOG` и `PHONE` заявлены в Declared Permissions Form | ⬜ до релиза |
| Основная функция приложения — телефония (условие допуска) | ✅ да, диалер |
| Приложение запрашивает роль DIALER, а не работает «мимо» | ✅ |
| Видеодемонстрация сценария использования разрешений | ⬜ снять |
| Объяснение каждого разрешения ДО системного диалога | ✅ экран онбординга |
| Приложение работает при отказе от необязательных разрешений | ✅ |

`SYSTEM_ALERT_WINDOW`: используется только для плашки активного вызова.
Не используется для рекламы, фишинга или перекрытия других приложений.

`SCHEDULE_EXACT_ALARM`: только для напоминаний, инициированных пользователем.
Это разрешённый Google сценарий; при отказе откатываемся на неточный будильник.

## 2. Запрещённые практики — проверка «от обратного» ❗

| Запрет | У нас |
|---|---|
| Accessibility Service не по назначению (запись звонков) | ✅ не используется вообще |
| Запись разговоров сторонним приложением | ✅ отсутствует |
| Скрытая функциональность, отличная от заявленной | ✅ нет |
| Реклама в системных уведомлениях или поверх окон | ✅ рекламы нет |
| Тёмные паттерны в подписках | ✅ подписок нет |
| Сбор данных без раскрытия | ✅ сбора нет |
| Обход ограничений на видимость пакетов | ✅ используем `<queries>` |

## 3. Data Safety ❗

| Поле формы | Ответ |
|---|---|
| Собираются ли данные | **Нет** |
| Передаются ли третьим лицам | **Нет** |
| Шифрование при передаче | Н/П — передачи нет |
| Возможность удаления данных | Удаление приложения / очистка данных |
| Обоснование | Разрешение `INTERNET` отсутствует в манифесте |

⚠️ Если когда-нибудь появится онлайн-функция, форму нужно переписать
**до** публикации сборки, а не после.

Внешние определители номера через `ContactsContract.Directory` — это передача
данных **сторонним приложением**, не нами. Функция выключена по умолчанию
и включается пользователем явно. В описании в Play это стоит упомянуть.

## 4. Обязательные материалы

- ⬜ Политика конфиденциальности по публичному URL (файл готов: `legal/`)
- ⬜ Иконка 512×512 (готова: `store/`)
- ⬜ Feature graphic 1024×500 (готова: `store/`)
- ⬜ Скриншоты: минимум 2, рекомендуется 6–8
- ⬜ Краткое (80) и полное (4000) описание, локализованные на en и ru
- ⬜ Возрастной рейтинг через анкету IARC
- ⬜ Контактный email разработчика

## 5. Технические требования

- ✅ `targetSdk = 35`
- ⬜ Формат App Bundle (`.aab`), не APK
- ⬜ Play App Signing включён
- ⬜ Закрытое тестирование: ≥12 тестеров, 14 дней подряд
      (для новых аккаунтов разработчика)
- ✅ Edge-to-edge (обязателен с Android 15)
- ⬜ Проверка на Android 15 и 16

## 6. Доступность (влияет на ранжирование и на отзывы)

- ⬜ Все интерактивные элементы ≥ 48 dp
- ⬜ `contentDescription` у каждой иконки-кнопки
- ⬜ Контраст текста ≥ 4.5:1
- ⬜ Прогон TalkBack по основным сценариям
- ⬜ Проверка при системном шрифте 200%

## 7. Что проверить в самой сборке

```bash
# Разрешения в готовом APK
aapt dump permissions app/build/outputs/apk/release/app-release.apk

# Отсутствие INTERNET (ломает сборку в CI)
./scripts/check_no_internet.sh
```
