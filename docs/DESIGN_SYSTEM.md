# Дизайн-система Ogneliss Dialer

Действует с 1.3.4 (04.10.2026). Основа взята из фактического кода
(аудит, раздел «Дизайн-система»), а не придумана с нуля. Любая новая
правка интерфейса — по этим правилам; исключения записываются здесь.

## Где лежит

| Что | Файл |
|---|---|
| Палитра, темы (светлая, тёмная, AMOLED, высокий контраст) | `ui/theme/Color.kt`, `Theme.kt` |
| Стили текста | `ui/theme/Type.kt` |
| Радиусы и формы | `ui/theme/Shape.kt` (`OgnelissShapeTokens`) |
| **Шкала отступов** | `ui/theme/Space.kt` (`Space.xs … xxl`) |
| Размеры компонентов | `ui/theme/Dimens.kt`, `ui/theme/FlowUi.kt` |
| Иконки | `ui/theme/OgnelissIcons.kt` (генерируется `scripts/build_icons.py`) |

## Цвета

| Назначение | Токен |
|---|---|
| Страница | `background`, `surface` — светлая `#F3F4F7`, тёмная `#121316` |
| Карточка, шторка, диалог, меню | `surfaceContainerLow` / `Container` / `High` — в светлой белые |
| Кнопка на карточке, строка выбора в диалоге | `surfaceContainerHighest` |
| Нижняя панель и всё, что в ней | `PanelColors.panel()` и `PanelColors.key()` |
| Управление, выбор | `primary`, `primaryContainer` |
| Звонок — **только звонок** | `CallGreen` |
| Сообщение | `MessageBlue` |
| Необратимое, пропущенный, отклонить | `error`, `BlockRed`, `DeclineRed` |
| Текст основной / второстепенный, иконки | `onSurface` / `onSurfaceVariant` |
| Разделитель / рамка | `outlineVariant` / `outline` |

Палитра с 1.4.0 — один холодный серый (семейство фона значка `#2E3138`)
и спокойный синий `#2F5DA3` / `#A8C2EC`. Модель в обеих темах одна:
всё над страницей светлее неё; нижняя панель — своя зона из двух цветов
(панель и клавиша). Контраст — `python3 scripts/palette_check.py`.

Правила:
- зелёный — только звонок, один оттенок на тему; красный — только
  необратимое и пропущенный;
- нажатие и выбор — системные слои Material 3, без своих оттенков;
- **без полупрозрачных версий цветов действий**: полупрозрачный зелёный
  поверх карточки — уже другой зелёный (1.3.4: подсказка свайпа — сплошной
  фон, обратная связь в значке);
- тени не используются — уровни показываются цветом поверхности;
  `tonalElevation` не используется (`surfaceTint` прозрачный);
- синий — состояние и выбор (включённый динамик, отмеченная строка,
  кнопка действия), а не украшение значков: значки кнопок нейтральные;
- в нижней панели два цвета — `panel()` и `key()`; третьего оттенка
  (своя подложка поверх панели) не вводить;
- нижняя панель доходит до края экрана: внутри панели — `PanelReachesNavBar()`,
  корень красит полосу под навигацией её цветом (1.5.1, `NavBarStrip.kt`).

## Текст

| Назначение | Стиль |
|---|---|
| Заголовок экрана | `titleLarge` |
| Имя в строке журнала | `titleMedium` |
| Подпись раздела («СЕГОДНЯ», «НОМЕРА», «ВЫЗОВЫ») | `SectionCaption`: `labelMedium` SemiBold, заглавными, разрядка 0,8 sp |
| Основной текст | `bodyLarge` |
| Вторая строка (дата, номер) | `bodyMedium` |
| Третья строка (оператор, регион) | `bodySmall` |
| Кнопки | `labelLarge` |
| Подписи под кнопками | `labelMedium` |
| Мелкие подписи, плашки | `labelSmall` |

Размер шрифта числом в экранах не задаётся. Исключение — экран вызова:
`FlowUi.callNameSize` / `callNumberSize` (видно издалека).
Подпись, которая может не поместиться, — `FitText` (ужимает, а не переносит
посреди слова).

## Отступы — `Space`

| Токен | dp | Где |
|---|---|---|
| `Space.xxs` | 2 | межстрочный зазор, поле плашки (с 1.3.5) |
| `Space.xs` | 4 | между карточками, значок — подпись |
| `Space.s` | 8 | внутри плотных групп, вертикальное поле карточки |
| `Space.m` | 12 | поля экрана, между блоками в панели |
| `Space.l` | 16 | горизонтальное поле карточки и панели |
| `Space.xl` | 24 | между разделами, нижнее поле шторки |
| `Space.xxl` | 32 | крупные разрывы: пустые состояния |

Компонентные поля: экран — `FlowUi.screenPadding` (12), карточка —
`FlowUi.cardPadding` (16 × 8), между карточками — `FlowUi.cardSpacing` (4),
шторка — `FlowUi.sheetPadding` (20).

**Проверка:** `prebuild_check.py`, правило 40 — отступ числом со шкалы
(`16.dp` в `padding`) — замечание с подсказкой токена. Значения вне шкалы
— осознанные исключения (разобраны в 1.3.5, все 40):

| Значение | Где | Почему не шкала |
|---|---|---|
| 6 dp (11) | вертикальное поле строк журнала и контактов, зазоры в метаданных | из него складывается высота строки; 4 или 8 изменили бы каждую строку |
| 56 / 76 dp | отступ разделителя до начала текста (шторка / журнал) | геометрия строки (иконка или аватар + поля), а не отступ |
| 1, 3, 10, 14, 36, 40 dp | плашка SIM, клавиша, подпись клавиатуры, заготовка журнала, выбор действия, кнопки псевдозвонка | единичная точная подгонка |
| 20 dp (4) | пустое состояние, мастер разрешений, список блокировки, экран вызова | вне шторок; в шторках 20 — это `FlowUi.sheetPadding` |

## Радиусы — `OgnelissShapeTokens`

**Сплошной список с 1.5.3, мягче с 1.5.5** (автор, макет «B» —
`docs/strict_style_1.5.1.png`; смягчение — `docs/soft_style_1.5.5.png`):
страница и шторки — #FAFBFC (не чисто белые), строки во всю ширину без
скруглений и рамок, линии между строками — от начала текста; разделы —
мягкие серые полосы `SectionBand` (`surfaceContainer` #F0F2F5) без линий,
подпись обычным регистром (`labelLarge`, Medium, `onSurfaceVariant`).
Группы `SheetGroup` в шторках разделены линией с полями 24 dp по бокам,
над группой меню — подпись, строки внутри без линий. Белыми остались
диалоги, меню и клавиши. Текст — #22252B / #50555E (было #1B1D21 / #454951).

Скругления: 6 · 10 · 14 · 18 · 24 dp (extraSmall … extraLarge) — для полей,
цветных выносок, шторок, диалогов; нижняя панель — 24 dp сверху.
(1.5.1–1.5.4 — 4 · 6 · 8 · 8 · 12 dp, подписи капителью, полосы с линиями:
автор — «резко и угловато».)
**«Пилюли»** — кнопки (`Button`), клавиши набора, строка номера, поиск,
кнопки вызова, плашка состояния (`dialKey`, `callButton`). Круглые —
аватары и кнопки-значки (`CircleShape`).

(1.5.1–1.5.2 — макет «A»: белые группы с рамкой на сером, кнопки 8 dp.)

## Компоненты

- **списки — один шаблон** (1.3.5): строки одной группы (дата в журнале,
  буква в контактах, избранные) — в одной карточке; скругление у первой
  и последней строки, разделитель от начала текста; место строки —
  `GroupPosition.of(индекс, размер)`, общий для журнала и контактов;
- **иконки в шторках — нейтральные**; цветные только опасные пункты
  (красным). Исключения со смыслом: иконка действия свайпа в его выборе
  (предпросмотр цвета), серая «Мой номер», пока номер не задан;

- строка списка — от 56 dp; область нажатия — от 48 dp (`Dimens.MIN_TOUCH_TARGET`);
- кнопки вызова на клавиатуре — `CallGreen`; без номера — `surfaceContainerHighest`;
- аватар — 48 dp (60 в крупном режиме); у контакта без фото — буквы на `primaryContainer` (`Initials.of`), у незнакомого номера — серый значок; кнопка вызова — 56 dp (72);
- пропущенный в журнале — красные стрелка и дата; аватар не перекрашивается (1.4.0);
- заголовок группы (`LetterHeader`) — полоса раздела `SectionBand`;
- действие в карточке — круг 48 dp с подписью `labelMedium`; значок нейтральный
  (`onSurface`), цветные — звонок (зелёный круг) и блокировка (красный значок);
- кнопки справа в строке (звонок, написать, скопировать) — 48 dp с иконкой
  24 dp, одинаково для номеров и почты;
- строка шторки — `SheetRow`; строка-состояние с переключателем —
  `SheetSwitchRow` (вся строка нажимается);
- необратимое в шторке — красным, последним в группе или отдельным блоком
  внизу; всегда с подтверждением.

## Иконки — Material Symbols Rounded

- только `OgnelissIcons` (Material Symbols Rounded, выбор автора 04.10);
  `androidx.compose.material.icons` не подключать;
- **контур** (FILL 0, вес 400) по умолчанию; **залиты** только там, где
  заливка несёт смысл: звонок, отбой, «закреплено», «избранное»;
- 24 dp по умолчанию, 18 dp в тексте, 14 dp мелкие, 12 dp в плашках;
- цвет — `onSurfaceVariant`; исключения: звонок (`CallGreen`), опасное
  (`error`), выбранное (`primary`);
- значки уведомлений — `res/drawable/ic_stat_*`, Symbols, свой у каждого
  типа уведомления;
- новая иконка — строка в `scripts/icons_manifest.json` и
  `python scripts/build_icons.py`.

## Значок приложения

- тёмный фон `#2E3138`, белая трубка, оранжевое пламя `#F7A901` с белой лисой —
  одна серия со значком Ogneliss Mail (`#2F343A`, белый конверт, то же пламя);
- цвета — `brand_dark`, `brand_flame` в `res/values/ic_launcher_background.xml`;
- все размеры — из `store/source/icon_master_1024.png` скриптами (`scripts/README.md`).

## Клавиатура набора

- клавиши — пилюли (`dialKey`; в 1.5.1–1.5.2 были 8 dp) цвета `PanelColors.key()`, нажатие —
  `primaryContainer`; цифра `headlineMedium` слева, буквы столбиком справа:
  буквы языка `labelLarge`, под ними латиница `labelSmall` `outline`; пара —
  по центру клавиши, ячейки фиксированной ширины (цифры ровным столбцом);
- строка номера — та же форма, что клавиши; номер по центру (`displaySmall`), подсказка
  `headlineSmall` `outline`; без подложки нельзя (контраст на панели);
- кнопки SIM — `CallGreen`; без номера — тоновые (фон 16%, текст зелёный).

## Карточка контакта

- быстрые действия (Позвонить, Написать, Поделиться, Напомнить, Блок) —
  в нижней панели стоя; в колонке шапки на широком экране;
- шапка с фото: затемнение внизу, имя белым `headlineMedium`, нижние углы
  фото 28 dp; без фото — аватар и имя `titleLarge`;
- блоки показываются по смыслу: отметка спама — у незнакомых номеров
  или когда отметка стоит; пустая заметка — одной строкой;
- история вызовов — группами по датам, как журнал, одна строка на вызов.

## Экраны вызова

Настоящий вызов (`InCallActivity`) и псевдозвонок (`FakeCallActivity`)
выглядят одинаково (`call/CallScreenParts.kt`):

- портретная раскладка с фото контакта — фото на весь экран, под строкой
  состояния, с затемнением сверху; имя и состояние — светлым
  (`OnPhotoColors`); значки строки состояния — светлые;
- управление — в нижней панели (`bottomPanel`, `PanelColors.panel()`); кнопки —
  `key()` с нейтральным значком, включённая — залита `primary`; второй вызов,
  конференция, тоновый набор — тоже `key()`;
- без фото, лёжа и в позе «ноутбук» — прежний вид, панель та же.
- без фото на весь экран — живой фон (1.5.1, `CallAmbientBackground`): пятна
  контейнерных цветов темы по состоянию (синий — входящий и соединение,
  зелёный — разговор, серый — удержание); 30 кадров; настройка и системное
  «Убрать анимацию» его останавливают; в высоком контрасте не рисуется.
  Волны от аватара (1.5.4, толщина по пути — 1.5.5): не линия, а мягкая полоса — текстура
  `softRing` 256 px с радиальным профилем (пусто до 58 %, долгий подъём
  от фона к цвету `primary` — «тень» за гребнем, гребень на 91 %, короткий
  спад к краю); тонируется один раз, в кадре только масштаб и прозрачность,
  поэтому толщина растёт вместе с радиусом. Пример — `docs/call_waves_1.5.4.png`.
  1.5.5: четыре текстуры от узкой к широкой (`RING_INNER`, `RING_CREST`),
  смешение соседних по пути волны — толщина растёт быстрее радиуса;
  появление в первые 10 % пути, угасание (1 − p)^2,4; лёгкое «дыхание»
  формы ± 3,5 %; свечение за именем вспыхивает с каждой волной; десять
  всплывающих искр, волна их подсвечивает. `docs/call_waves_1.5.5.png`.
